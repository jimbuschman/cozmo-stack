# EQ persistent coefficient dependency graphs

Primary: `20261009-sound-eq-parameter-graphs-native.txt` plus the already positive type1 branch in `20261008-sound-eq-coefficient-boundary-native.txt`. Engine SHA256 02263c07f6bb60f4d7f351a3667dca84fd3e6c0fc6f838e18b5de7cf4e2989e1. Generated by `20261009-sound-eq-parameter-graphs.py` directly from the captured instructions. This is a research description, not production code or a numerical equivalence test. All offsets hex.

Each vADDRESS names one native scalar operation. Copies remain aliases; raw constants use F32(hex). VMLA names the old destination before its two multiplicands, preserving association, including zero multiplication. Imported phone math arguments/call order and returned-value dependencies are exact; phone bodies remain external. SQ merges native VSQRT with its conditional imported sqrtf fallback; the comparison is the native result with itself. No PCM inputs, recurrence or sample loop.

Entry inputs: P=plugin, tuple={kind at0,gain at4,frequency at8,Q atC}; band index is unchecked. Rate is unsigned P48 converted by AA2608. AA260C/2610 compute F32(F32(rate*F32(3F000000))*F32(3F666666)). AA2614/261C selects that cap when ordered frequency>=cap, otherwise keeps frequency, including unordered. Types0..6 select the branches below. Unsigned kind>6 goes directly to AA272C with incoming live coefficient registers, not an identity or error fallback. F9/F11 and LP434 own parameter and consumer joins.

Types4/5 reload unsigned P48 after powf; other types use the converted entry rate. Default parameter kinds and concrete raw authored inputs are in LP434; this graph adds no inferred band names.

Common output base=P+20(decimal)*band. Exact store order: AA2748 +4=s14/s11; AA2754 +8=s13/s11; AA275C +10=(-s16)/s11; AA2768 +14=(-s15)/s11; AA276C +C=s10/s11. Arithmetic interleaves as shown in each graph; VPOP at AA2760 does not restore s9..s15.

out of scope: per-sample biquad arithmetic under ADP-1; allocator/storage infrastructure and excluded source branches under scope guard.
