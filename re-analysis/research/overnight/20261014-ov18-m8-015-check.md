## R8: dock actions at ~Robot

- **A started action can't survive Cancel(−1):**
  - every queue's non-null current is cancelled and deleted (0x0053E69A..0x0053E6B6);
  - current is set only by Queue::Update's promotion (0x0053F60C), which runs only from Robot::Update, and nothing
    between AbortAll and Clear calls it;
  - Delete rejects only a re-entrant delete of the same action, and the outer frame still finishes it;
  - tags are unique (0x0053FE54..0x0053FE7A).
- **A pending action can survive, in mechanism,** through a synchronous completion callback:
  - **a re-queue after the last pending deletion:** the iterator advances before the broadcast (0x0053FA86..0x0053FAB2;
    0x0053E6E8..0x0053E6EE);
  - **a QueueNow front insertion** while other pending actions remain;
  - **AddConcurrentAction** into a key gap below the traversal point.

  The callbacks are synchronous: every IBehavior subscribes to tag 0x5A (0x005BBD5E..0x005BBD7A), and StartActing queues
  NOW. **Whether shipped code does this is unread:** that's the new T3 record.
- **The 0x005A3A84 null read is not reachable through R8:**
  - every survivor is NOT_STARTED (ctor 0x02000001; no Update; pending deletes never Cancel);
  - the IDockAction dtor (0x00557448) skips the first RemoveDisableReactionsLock when NOT_STARTED
    (0x00557514..0x0055751E), and the second when +0xC4 == 0 (0x0055754E..0x00557552);
  - **+0xC4 is written only by FacePlantAction** (0x00552B7E). That is built only by the G2E RobotActionUnion factory,
    and the app never sends it, so it's SDK-only (out of scope).

  **No M1-034 row is needed.**
- **What stays defined if a pending dock survives:**
  - DeselectCurrentObject;
  - Path Abort if active;
  - AbortDocking if DockingComponent+4 is set (AbortAll's send doesn't clear it);
  - +0x10 = 3 and +0xC = −1;
  - the cube light if +0xF6;
  - RemoveSquint;
  - the RobotCompletedAction broadcast.

## New rows (M8-015)

- **T2, List Clear** (0x0053D916..0x0053D93A, 0x0053F938..0x0053F950):
  - return at once if +0xC is already set;
  - otherwise set +0xC; destroy the queue tree **post-order** (left, right, node; 0x0053FB5C..0x0053FB82); reset the map;
    clear +0xC;
  - ~ActionQueue: Queue::Clear, destroy the guard set, free the list nodes (not the actions).
- **The QueueAction front end** (0x0053D93C..0x0053DAC8):
  - **A null action:** Error "ActionList.QueueAction.NullAction" "Can't queue null action", `_errG`, break-on-error,
    return 1. No delete.
  - **robot+0x2C7 set, with a tag in [1, 1000000] or [2000001, 3000000]:**
    - Info "Unnamed" "ActionQueue.QueueAction.ExternalActionsDisabled" "Ignoring %s action while external actions are
      disabled" (EnumToString(type));
    - create queue key 0 if it's absent;
    - a full DeleteActionAndIter (it broadcasts NOT_STARTED);
    - return **0**.
  - **BAD_TAG with +0x2C7 == 0:** Error "ActionQueue.QueueAction.ActionHasBadTag" "Failed to set tag, deleting action %s",
    `_errG`, the same delete, return 0.
  - The +0x2C7 writers (BehaviorManager 0x005A2110, 0x005A2F60) are M8-001's.
- **The position table** (`tbb` at 0x0053DA2A):

  | Position | Goes to |
  | --- | --- |
  | NOW | QueueActionNow |
  | NOW_AND_CLEAR_REMAINING | the guard, Cancel(−1), then **QueueActionNext** |
  | NOW_AND_RESUME | QueueActionAtFront |
  | NEXT | QueueActionNext |
  | AT_END | QueueActionAtEnd |
