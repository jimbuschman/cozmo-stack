## Checked rows

`SetMarkerAsObserved(ObservedMarker* m, u32 ts, float tol)`:

1. **Setup:**
   - a temporary empty string names a stack Pose3d (sp+0x7C). The string's buffer is freed **immediately** after
     (0x00876DCE..0x00876DE4);
   - obsCentroid = ComputeCentroid(m+8) (0x00876DF0);
   - obsArea = ComputeArea(m+8) (0x00876DF6);
   - inv = 1.0f / obsArea (0x00876E4C).
2. **The lookup:** find<short>(this+0x34, the code at m). If it isn't found, Warning 1 (0x00876E06..0x00876E0C). If the
   vector at +0x14/+0x18 is empty, Warning 2 (0x00876E12..0x00876E18).
3. **The loop over the KnownMarker\* elements,** in order. best = FLT_MAX (literal **0x7F7FFFFF at 0x00877054**), and
   bestNode = 0.
   1. GetWithRespectTo(node+4, m+0x34, &pose) must return 1 (0x00876E56..0x00876E64).
   2. Get3dCorners(node, pose), then Camera::Project3dPoints(m+0x28) into a zeroed quad, then Contains(obsCentroid)
      must return 1 (0x00876E68..0x00876E94).
   3. d² = (projCentroid.x − obsCentroid.x)² + (projCentroid.y − obsCentroid.y)², with f32 subtractions per axis, then
      the squares, then their sum (0x00876E96..0x00876ED4). It must be **< best** (`vcmpe`/`bpl`; NaN and equal skip,
      0x00876ED8..0x00876EE0).
   4. The area ratio (0x00876EE2..0x00876F5C):
      r = inv·(0.5·|c1| + 0.5·|c2|) − 1.0
      where c1 and c2 are the two triangle cross products of the projected quad. Then r = |r| (`mi` negate).
   5. If r < tol (`mi`; NaN fails), then best = d² and bestNode = node (0x00876F60..0x00876F74). The first marker wins a
      tie.
4. **After the loop:** if bestNode ≠ 0, store `*(u32*)(bestNode+0x48) = ts` (0x00876F86) and return. Otherwise,
   Warning 2.
5. **Warning 1** (0x00876F8A..0x00876FAC): sWarningF, key "ObservableObject.SetMarkerAsObserved" (0x008770A4), data =
   an **empty key/value vector** (sp+0x20, zeroed at 0x00876F8C), format "No markers found with code (%d:%s) of given
   'nearestTo' observed marker", args (signed code, GetCodeName).
6. **Warning 2** (0x00876FAE..0x00876FC4): key "ObservableObject.SetMarkerAsObserved.NoMatchingMarkerFound"
   (0x00877058), an empty data vector, format "Marker:%s" (0x00877094), arg GetCodeName(m).
7. **After either warning:** free the data vector's buffer if it's non-null, then destroy the Pose3d, and return void
   (0x00876FC8..0x00876FF8). **The only persistent write is the timestamp.**

## Corrections to OV85

- **FLT_MAX** is 0x7F7FFFFF at 0x00877054, not 0x624F7F7F at 0x00877056.
- **The warning's second argument** is an empty data vector, not "the empty string". The string is freed right after
  the Pose3d is constructed.
- **The distance** is from the projected centroid to the **observed** centroid, not cx² + cy². NaN skips.
- **The plural SetMarkersAsObserved rows** came from the decompiler. They aren't adopted here.

## The +0x48 / +0x50 note

The store is at KnownMarker+0x48. B-M11-3's consumer reference to "node+0x50" must be reconciled in the build: either
the consumer reads through a container node with an 8-byte header, or the build must cite this +0x48 store directly.
