## Queries and cache

HasBorders searches the processor's combination tree at +0x14 (root +0x18) by unsigned 64-bit key `(uint64(seed) << 32) | mask`. A found combination with dirty byte node+0x18 zero returns whether waypoint begin/end node+0x1C/+0x20 differ. Missing/dirty falls through 0x0068939A to HasBorderSeed, via the ARM veneer whose literal at 0x008CD868 resolves to PLT 0x004BD140. It does **not** refresh or mark that combination clean.

HasBorderSeed finds the seed's type set. Missing type returns false. It reserves a temporary neighbour vector for `1 << root.level` (0x006893DE..0x006893E8). For each node in the set's existing linked iteration order, enumerate directions 0,1,2,3, clearing the temporary vector before each AddSmallestNeighbors(direction, clock=0). For each returned neighbour, obtain content, read type byte +4, call EContentTypeToFlag, AND the mask. First nonzero returns true; exhaustion returns false. Temporary references and vector storage are released. No geometric float test or direct log occurs in these two query bodies. Null content dereferences at 0x00689444 remain an M1-034 case with M11-079 as owner; this report does not invent a result for defined inputs.

RefreshBorderCombination emplaces the exact combination, with the kDebugFindBorders byte at 0x00C88161 as a constructor argument; only dirty combinations call FindBorders (0x00689AD2..0x00689AE0). Its own body has no direct log. FindBorders/cache invalidation belong to M11-047/045 and the checked OV11 extraction.

## GetBorders, in execution order

Refresh occurs **before** clearing output (0x006894EE versus 0x00689500). Existing regions are removed from the back and their segment vectors destroyed. Capacity can remain. No waypoints returns immediately. Otherwise initialize a local pointer set (maximum load factor 1), set start A and previous B to the first waypoint centre, initial content C to the first source node's NodeContent, and start direction D to the first direction. Constants are f32 bits `0x3727C5AC` (epsilon), `0x3F7C1BDA` (angular threshold), `0x3A83126F` (millimetres-to-metres), and positive zero (0x00689564..0x00689570).

For every waypoint i, including zero:

1. Insert its **source** node pointer into the local unique set (0x00689580..0x006896E4). The hash is the shipped four-byte pointer hash 0x005198E0; the set inserts/rebuckets using libc++ semantics. No duplicate area contribution. The end flag is byte waypoint+0xC, read before helper calls at 0x0068958E. Start flag +0xD is not consulted here.
2. Calculate current centre P. Compute `v=B-A` per coordinate in f32, then `q=((vx*vx)+(vy*vy))+(vz*vz)` with separate multiply and add instructions in XYZ order. If ordered q<0 negate q (not a bitwise abs); if ordered q<epsilon skip normalization/angle and proceed to content comparison. Equality at epsilon takes the angle path. NaN q takes the angle path (`bmi` at 0x00689766 is false for unordered).
3. Angle path: call MakeUnitLength on v; compute `w=P-B` and call MakeUnitLength on w; dot product in XYZ order with separate f32 products and adds. `blt` at 0x006897CC splits on ordered dot<threshold **or unordered** (VFP unordered N=0,V=1). Equal threshold continues to content equality. Thus a C# ordered `<` alone is not the native branch predicate.
4. Unless angle already splits, compare C with the current source's NodeContent (0x006897DA..0x006897E0); unequal splits. NodeContent operator== (0x0068C4BE..0x0068C4E2) first reads both type bytes, rejects different types, accepts identical pointers, otherwise dispatches the first data object's vtable+0xC with the second pointer. It is **not** merely equal type. Concrete virtual equality bodies are an unread interface in this answer; see below.
5. On split, choose the last output region only if its area is ordered negative; otherwise append a region with area bits `0xBF800000` and empty segment vector. The branch is `blt` at 0x0068980A: unordered area also reuses the last region. Emit MakeBorderSegment(A,B,C,D,waypoints[i-1].direction), appending a 44-byte segment and transferring its shared content reference. Then A=B, C=current source content, D=previous waypoint direction (0x006897E8..0x006898E2). The native reads direction at current waypoint address-8; malformed input that causes a split at i=0 reads before the vector at 0x006897F6. Record under M1-034 rather than add an uncited native guard.
6. Always B=P. If end byte was zero, increment and continue; there is no implicit final flush just because i is last (0x006898E4..0x006898F0, 0x0068993E).
7. If end byte is nonzero, choose/append an unfinished region with the same ordered-negative/unordered behavior (`blt` at 0x00689912); emit MakeBorderSegment(A,B,C,D,current.direction), even for coincident endpoints. Iterate the local source-node hash list, starting area at +0: for each node compute `s=f32(node.side * bits(0x3A83126F))`, then `area=f32(area+f32(s*s))`. Clear the local set and store area (0x006899D0..0x006899FC).
8. If another waypoint follows, initialize A=B=its centre, C=its source content, D=its direction; then process that next waypoint normally, including inserting its source pointer. On complete traversal destroy the local set (0x00689A00..0x00689A58).

No direct logging call or robot/game message occurs in GetBorders or its two geometry helpers. Allocation/unwind paths release temporary shared references/set storage and resume the exception (0x00689A5C..0x00689AA6); they do not return a guessed empty result.

The seed-order policy M11-047 does not by itself establish a replacement for the **local area set's addition order**: the hash list also depends on pointer values and rehash. Binary32 area sums can depend on this order. Preserve this as a named unresolved boundary unless the manager establishes an already-approved policy or proves order independence over all reachable node side values. This answer does not extend the seed-order departure.

## Geometry helpers

CalculateBorderWaypointCenter uses unsigned level bytes: if source.level > neighbour.level, use neighbour; otherwise source, including ties. Direction normal is the original source-to-neighbour direction (directions 0..3 map to +X,-Y,-X,+Y). For neighbour-selected, each result coordinate is `neighbour.centre - f32(f32(neighbour.side * normal) * 0.5f)`; for source-selected it is `f32(f32(source.side * normal) * 0.5f) + source.centre`. Two multiplications and final subtraction/addition occur separately, XYZ order (0x00689B1A..0x00689B88; 0x00689B8C..0x00689BFC). There is no coordinate midpoint, height discard or epsilon. Invalid direction normal is the separately owned EDirectionToNormalVec3f zero-vector case; node pointers are dereferenced without null guards.

MakeBorderSegment first gets normal N0 for start direction, computes tangent `t=end-start` and calls MakeUnitLength. Ordered-negative returned length is negated. If ordered length<epsilon, calculate normal as `(N0+N1)*0.5f` with separate f32 operations, **without normalization** (0x00689C7A..0x00689CD6). Equality/NaN length takes the other path (`bpl` at 0x00689C78).

For that other path, candidate normal is `(-t.y,t.x,t.z)`, not a cross product that zeroes Z. Dot candidate with N0 sequentially in XYZ; keep candidate for dot>0 **or unordered** (`bhi` at 0x00689D30); otherwise negate candidate X and Y only, including dot equal zero. Z is never negated here. Copy original start/end XYZ, resulting normal XYZ, content pointer/control block into segment offsets 0,0xC,0x18,0x24/0x28 and increment shared ownership when present (0x00689D46..0x00689D76).

MakeUnitLength's body is 0x0050E0C0..0x0050E130. Sequential XYZ squared sum uses f32 products/adds. `ble` after comparison with zero returns +0 for ordered nonpositive **or unordered**, with the input vector unchanged. Otherwise take hardware `vsqrt.f32`; only unordered sqrt invokes platform sqrtf with the **squared norm** (r0 loaded from s2 at 0x0050E0FC). Compute one f32 reciprocal then multiply each coordinate by it. Return original length, not squared length. Infinity gives reciprocal +0 and permits Inf*0 NaNs; no finite-value filter. These arithmetic paths are outside ADP-1's audio exception.
