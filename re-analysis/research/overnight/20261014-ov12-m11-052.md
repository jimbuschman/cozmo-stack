## GetRawStateAt: complete decision path

1. **Range and search — M11-052, candidate IMPLEMENTATION_GAP.** Body entry is even address **0x00531430**; 0x00531431 is its Thumb symbol. Search the raw-state ordered tree with **unsigned** timestamp comparisons for lower_bound(t), at 0x0053143A..0x00531466. Empty tree, lower_bound=end (t later than the newest state), or first stored key>t returns **1**, at 0x00531466..0x00531476. Neither output key nor output HistRobotState is written on these returns. There is no extrapolation, maximum-gap test or wrap-aware signed timestamp comparator in this function.
2. **Exact timestamp — M11-052, candidate IMPLEMENTATION_GAP.** If lower_bound.key==t, write output key=t, assign its PoseBase to the output, copy **0x5B bytes** of RobotState from node+0x20 to output+0xC, and return **0** (0x0053147A..0x0053149E). This happens before the interpolation flag and all pairwise frame/origin checks. The copy excludes the last byte of the native 0x5C-byte allocation, not the current path-segment byte. PoseBase assignment uses the existing pose-tree assignment contract rather than assigning a managed reference to the source wrapper.
3. **Bracketing pair and frame guard — M11-052, candidate IMPLEMENTATION_GAP.** Otherwise A=lower_bound and B=its immediate predecessor, found by rightmost-left-subtree / ancestor walk (0x005314A0..0x005314B8). Load B and A **node+0x24** and compare; mismatch logs L1 below and returns **0x06000000**, with caller outputs unchanged (0x005314BA..0x005314C0, 0x00531564..0x00531582, 0x0053162E). This guard applies even when interpolation is disabled.

The layout proof is explicit: HistRobotState begins at tree node+0x14, and embeds RobotState at +0xC, hence RobotState begins at node+0x20. RobotState native unpack reads timestamp at +0, next u32 at +4, next u32 at +8 (0x007D6E24..0x007D6E4C); shipped generated `unity/scripts/csharp/Anki.Cozmo/RobotState.cs:306` onward names these in the same order **timestamp, pose_frame_id, pose_origin_id**. Therefore +0x24 is frame ID. The log itself says frame IDs. A numeric origin-ID equality test at node+0x28 is absent here.

4. **Interpolation flag — M11-052, candidate IMPLEMENTATION_GAP.** Native compares the flag word to **1** (0x005314CA..0x005314CE). Canonical bool true enters interpolation; anything else follows row 6. For true, construct an empty-named temporary Pose3d, then call `GetWithRespectTo(A.pose,B.pose,tmp)` (0x005314D0..0x00531504). Return must equal 1. Otherwise destroy tmp and enter the common pose-origin failure path, L2, returning 0x06000000. It does not fall back to a nearest pose on failure.
5. **Fraction and interpolation success — M11-052, candidate IMPLEMENTATION_GAP.** For successful conversion, compute unsigned 32-bit differences `den=A.key-B.key`, `num=t-B.key`; separately convert den and num with **VCVT.F32.U32**, then `f=F(numFloat/denFloat)` (0x0053150C..0x00531524). Both conversions precede the division; a double quotient narrowed afterward is not the same recipe. No clamp follows. In a valid strict bracket den is nonzero and the real fraction is between zero and one, though f32 rounding may approach or reach an endpoint. Call Interpolate(B,A,tmp,f), assign the resulting pose to output, copy 0x5B RobotState bytes, destroy the intermediate state, then write output key=t and destroy tmp (0x00531528..0x0053155C). Return 0. The copied RobotState timestamp is **not** replaced by t by this routine.
6. **Intentional nearest mode — M11-052, candidate IMPLEMENTATION_GAP.** With flag!=1 call `A.pose.HasSameRootAs(B.pose)` at 0x00531588; return!=1 enters L2 and 0x06000000. Otherwise compute unsigned distances `t-B.key` and `A.key-t`. Choose A only if the second is **strictly less** than the first; equality chooses **B** (0x00531590..0x005315A4, 0x00531634..0x00531648). Write the selected endpoint's **key**, assign its pose and copy 0x5B RobotState bytes; return 0. This mode performs no blending and does not call GetWithRespectTo. The earlier frame guard still runs. Do not confuse its tie rule with the separate endpoint-field threshold inside Interpolate.

The raw-state tree is not mutated by these functions. Success modifies caller outputs; failure leaves their previous values. Exceptions from called constructors/assignments are not converted into either result code: cleanup landing pads 0x0053164A..0x005316AE unwind. No robot command, game-interface report, retry, timer or InterpolationStandIns increment appears in GetRawStateAt or Interpolate.

## Frame contract and exact blend

7. **Temporary frame — M11-066 dependency, recovered contract.** GetWithRespectTo checks nonnull pose nodes and same tree root at 0x00845A3E..0x00845A68. It copies the source and target transforms, aligns their ancestor chains with PreComposeWith, in the general case computes inverse(target-chain) times source-chain at 0x00845C72..0x00845CB4, writes into the output node and calls SetParent(output,target) at 0x00845DFA..0x00845E02. For A and B sharing a parent, this is `inverse(B.T)*A.T`, with tmp.parent=B. It is **not** A expressed in B's parent's frame. The input wrappers are distinct history entries on the interpolating path; the helper's `fromWrapper==toWrapper` warning branch is not an ordinary history-bracket case.

Current M11-066 already owns the chain walk, aliases and 1000-step diagnostics, and its 20261014 correction explicitly removes the earlier alleged immediate early exit when from.parent==to. The native checks the relevant ancestor relationship **after** a climb at 0x00845ACC..0x00845ADA; this report does not reinstate the older simplification. All successful exits converge on the output-parent write. Transform3d uses double quaternion and float translation arithmetic under M11-065/067; a shared dependency's outstanding work is not hidden by this caller contract.

Let `R` be the local RobotState, `F` one separately rounded binary32 operation, `B` before and `A` after. HistRobotState embeds RobotState at +0xC.

8. **Endpoint field source — M11-052, candidate IMPLEMENTATION_GAP.** Interpolate 0x0053068C loads **0x3EFFFEB0**, the exact f32 threshold approximately 0.49999. It copies **0x5C bytes** from B.R iff ordered `f<threshold`; otherwise from A.R, including equality and unordered/NaN (VCMPE/MI, 0x00530698..0x005306BE). This is not a 0.5 comparison. It then overwrites R+4, pose_frame_id, from B.R+4 (0x005306C2..0x005306C4). All fields not overwritten below stay from the selected endpoint: timestamp, numeric origin ID, embedded RobotPose, accelerometer, gyro, battery, status, touch and current path segment. The raw RobotPose bytes and the separately constructed historical Pose3d need not describe the same interpolated pose.
9. **Continuous scalar fields — M11-052, candidate IMPLEMENTATION_GAP.** Every blend is `F(B + F(F(A-B)*f))`, with subtraction, multiplication and addition as distinct f32 instructions. Execution order is headAngle R+0x28, liftAngle R+0x2C (0x005306CA..0x005306FA), cliff rule below, then left wheel speed R+0x20 and right wheel speed R+0x24 (0x0053073A..0x00530766). Head/lift are ordinary scalar blends here, not wrapped-angle operations. No FMA or f64 intermediate is used for these four fields.
10. **Cliff fields — M11-052, candidate IMPLEMENTATION_GAP.** First set **all eight bytes R+0x50..0x57 to 0xFF** (0x005306EE). Read only B.R+0x50 and A.R+0x50 as unsigned halfwords. Subtract in 32-bit integer arithmetic, convert the difference as **signed** to f32, convert B as unsigned to f32, multiply difference by f then add B, call imported `roundf`, convert the f32 return with VCVT.U32.F32, and store its low halfword into R+0x50 (0x005306FE..0x00530734). The finite in-range roundf contract rounds halfway away from zero. **cliffDataRaw[1..3] remain 0xFFFF.** There is no four-channel interpolation loop or sentinel special case. The call's bionic arithmetic body is an external libm boundary; its operands, call order and conversions remain exact.
11. **Translation — M11-052, candidate IMPLEMENTATION_GAP.** Copy B's transform translation and tmp's transform translation, multiply each tmp coordinate by f in x/y/z order, then add the three results to B's corresponding coordinates in x/y/z order (0x0053076A..0x005307BE). Result is `F(B.translation[k]+F(tmp.translation[k]*f))`. **No rotation of tmp.translation back into B's parent frame occurs in this body.** Knowing tmp's true frame is not permission to add one. Preserve this shipped formula even for a rotated B.
12. **Yaw and final pose — M11-052 with M11-065/067 dependencies, candidate IMPLEMENTATION_GAP.** Obtain B.angleZ then tmp.angleZ (0x005307C0..0x005307DC). Multiply tmp angle by f using Radians operator*; then add B angle using Radians operator+ (0x005307E0..0x005307F4). These helpers perform f32 multiplication/addition **and rescale after each** (0x0084CB28..0x0084CB42, 0x0084C860..0x0084C87A). Obtain Z_AXIS_3D, obtain **B.GetParent()**, construct an empty-name Pose3d from the resulting Radians, Z axis and translation, then construct HistRobotState from that Pose3d and R (0x005307F8..0x00530848). Final HistRobotState construction assigns the pose and copies only **0x5B bytes** of R (0x005304EA..0x005304F6). The caller later copies those same 0x5B bytes. The earlier 0x5C endpoint copy includes padding and is not evidence of a 0x5C final data copy.

For clarity on widths, native GetAngleAroundZaxis 0x0084AA1C..0x0084AAB8 uses quaternion doubles `(w,x,y,z)` to compute `u=F(2*(x*y-z*w))`, `v=F(1-2*(x*x+z*z))`, `a=F(2*(x*y+z*w))`, `b=F(1-2*(y*y+z*z))`; each product/sum before F is separately rounded double, and doubling is addition to self. Compare f32 `F(F(a*a)+F(b*b))` with `F(F(u*u)+F(v*v))`. Ordered greater selects `atan2f(a,b)`; otherwise, including unordered, use `atan2f(-u,v)` (sign-bit negation). Construct Radians from the return. Radians' finite unchanged range is **(-pi,+pi]**, with pi bits 0x40490FDB and two-pi 0x40C90FDB; exactly -pi becomes +pi. For finite abs(angle)<10 outside that interval it adds/subtracts two-pi in f32 until in range. For abs>=10 (and unordered abs comparison), the route is f32 divide by two-pi, subtract 0.5, ceilf, signed-int conversion, convert back to f32, multiply by two-pi, subtract from original (0x0084C87C..0x0084C936). This is not one final generic double modulo. The normal finite history fraction and wrapped inputs use the small-angle route; the exact generic helper remains shared-pose ownership.
