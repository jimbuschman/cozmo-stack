# Opus re-check 1 of the M9 MIDI path (M9-012, M9-013, M9-014), 2026-10-15

- **Follows:** `research/overnight/20261015-ov38-41-check.md`. This pass re-disassembles the rows that check didn't:
  - OV38's R1–R8 and E1–E12;
  - OV39's G1–G3 and G8, and the source-context consumers;
  - the M9-012 lead.
- **Method:** read-only cozmo-extractor, against libcozmoEngine.so (ARM, capstone with skipdata) and all six banks.
- **Adopted:** by the manager on 2026-10-15.

## Manager decisions

1. **M9-013 moves to IMPLEMENTATION_GAP.**
   - **The build rows:** R1–R8, E1–E12, the new rows below, plus OV38 F1–F5 and L1–L7.
   - **The new rows join M9-013,** since they're on its path: E2b, E4b, E7b, E7d and E9b.
   - **The boundary callees get one new RECOVERABLE_GAP record:** A04384, owner vt+4, A70C84 (CC 120/123), A717A4, A3EB4C,
     and the vt+0x70 / 981DBC branch with the 0x0097D1EC byte-set path.
   - **Owned elsewhere:** the parser A3F6E0 is M9-005; A3E920 is M9-031.
2. **M9-014 moves to IMPLEMENTATION_GAP.**
   - **The answer:** in shipped content, **MIDI velocity never changes voice level.**
   - **The build rows:** V1, V5–V8, G1–G4 and G8, the fade writers, and E7b's velocity inheritance.
   - **A new RECOVERABLE_GAP record:** the general parameter collector (9EF258, 9FBE74, A11590), unread. Its inputs carry
     no velocity.
3. **ADP-1 and the dB → linear polynomial** (0x00A4B608..0x00A4B674): it's gain arithmetic, so **it may be
   EQUIVALENT_IMPLEMENTATION**, subject to the equivalence test. Its inputs, and the decisions that pick them, stay
   exact: PBI+0x3C dB, PBI+0x40 linear, the cache gate, the fade writers.
4. **M9-012 stays EXACT_SOURCE,** because its conclusion holds on the real flag, but its **evidence is corrected.**
   - **Property 45** is the tracking root note.
   - **The enable flag** is NodeBase +0x47 bit3 (authored bit4).
   - **No shipped object sets authored bit3 or bit4.**
   - **The OV38–41 check's "15 Sounds set the authored bit 0x10" is withdrawn.** It isn't reproduced, and was likely a
     misaligned parse of the 15 plug-in Sounds.

## M9-013: the rows

- **R1:** `src+0x16 == 0x10` selects the MIDI factory (0x0099B8E8..0x0099B9FC).
- **R2:** a null 3rd argument returns 0x1F. The rest of R2 is at 0x00A3D234..0x00A3D318 (ctor 0x00A3BF84..0x00A3BFA8).
- **R3:**
  - the track flags (+0x94 bit0 = override, bit2 = table);
  - property 0x38 is read at the aligned index;
  - the writer maps authored bits (0x0099239C..0x00992424; 0x00992C00..0x00992C1C).
- **R4:** the parent walk (0x00A3BE4C..0x00A3BE88; 0x00987CB8..0x00987D30; 0x009877E4..0x00987800).
- **R5:** release, then the lookup (0x00A3BE04..0x00A3BF00; 0x009A7EB0..0x009A7FA8).
- **R6:** the property loader always sets +0x46 bit0 (0x009ED51C..0x009ED644); what that bit means is unread.
- **R7:** the Layer (0x009D273C..0x009D27C4).
- **R8:** the init order and gates (0x00A3CBE0..0x00A3CC84). The tails after 0x00A3CC88 are unread.
- **E1:** the frame callback (0x0097D14C..0x0097D1E4).
  - The MIDI update runs only when `(ctx+0x36 & 3) != 0` and bit 0x10 is clear (0x00983638..0x00983650).
  - The step is round(f32 frames × f32 +0x3C), using ±0.5 then `vcvt.s32` (0x00983680..0x0098370C).
- **E2:** per clip (0x00A3C4C8..0x00A3C538): elapsed = f32(s32(step − off)) / (f32(rate)/1000). **An elapsed of 0
  skips the parser.**
- **E2b (new):** after all clips, each queued offset is rescaled: s32(f32(off)/scale ± 0.5) (0x00A3D370..0x00A3D3B4).
- **E3:** pos = s32(f64(t)·f64(rate)/1000 ± 0.5). NaN or zero takes −0.5 (0x00A3C62C..0x00A3C72C).
- **E4:** the F8/FC gates (0x00A3C608..0x00A3C740).
- **E4b (new):** at the end of a clip, F8 = −1 means release only. Otherwise F8 := 0, and if FC bit2 is clear it's set and
  one extra reference is released (0x00A3C53C..0x00A3C57C).
- **E5:** the queue (0x00A70738..0x00A70888).
- **E6:** the drain (0x00A71B34..0x00A71BF0).
- **E7:** the target record, the growth (an allocation failure drops the event), and the holder (0x00A70DBC..0x00A71128).
  **A04384 (0x00A70F74..0x00A70F84) is a prefix call that rejoins the normal path**, not an alternate path.
- **E7b (new):** for a note-off or zero-velocity note-on, the head-first walk takes the first match (0x00A70F94..0x00A70FCC;
  0x00A3E568..0x00A3E684).
  - **An unmatched note-off is dropped.**
  - **A match against a sounding note-on:** the new holder becomes 0x80, takes the note-on's velocity and shares its note
    state, and the old holder gets bit2.
- **E7c (new):** CC 0xB0 with controller 0x78 or 0x7B calls A70C84 (0x00A71024..0x00A71048). That body is unread, and
  whether shipped content reaches it needs a scan of the 46 MIDI payloads.
- **E7d (new):** holders are inserted ordered by signed holder+0x18, stable for equal keys (0x00A70F20..0x00A70F68,
  0x00A71054..0x00A71060).
- **E8:** a failed allocation or an A3DE10 result ≠ 1 drops the note. A3DE10 returns 0x34 when a pool fails
  (0x00A3E460..0x00A3E560; 0x00A3DE10..0x00A3DF3C).
- **E9:** the held list (0x00A71938..0x00A71A4C, 0x00A71AD8..0x00A71B28).
- **E9b (new):** a note is retired when notestate+0x40 == 0 and +0x5C == 0, through A3EB4C (unread)
  (0x00A71A50..0x00A71AD0).
- **E10:** the per-note step (0x00A3EA3C..0x00A3EB44).
  - Non-note statuses return 1.
  - Note-off processing runs only when s32 off < u16 frames and bit1 is clear.
  - The countdown is max(0, off − step).
- **E11:** the replay (0x00A3E688..0x00A3E830).
- **E12:** the play request (0x00A3DD0C..0x00A3DE04). **R+0x88 is the note state, not the owner.**

## M9-014: the rows

- **G1:**
  - the cache gate, plus a factor-record purge (0x009FFAF4..0x009FFB0C, 0x009FFED4..0x009FFF20, 0x009FFB84..0x009FFBF8);
  - the early return when E9 bit2 is set (0x009FFC28..0x009FFC50).
- **G2:** V+0xC4 = 100.0f on every recompute (0x009FFC54..0x009FFD10).
- **G3:** the f32 product. A value ≤ 0 stores 0 to V+0x40 (0x009FFD14..0x009FFE18; 0x009FF368..0x009FF40C).
- **G8:** level = PBI+0x40 × dB2lin(PBI+0x3C), through the thunk 0x009FF414 at sub-vtable 0x0103B804 (0x00A4B5D8..0x00A4B674).
- **The fade writers** (new):
  - the ctor sets 1.0f (0x00A00134, 0x00A0022C..0x00A00230);
  - the transition callback writes them (0x009FF41C..0x009FF4C4);
  - stop and pause paths write 0, and resume writes 1.0 (0x00A00888, 0x00A01348, 0x00A01D6C, 0x00A021D4, 0x009FF750,
    0x00A0146C, 0x00A0166C).

  None of them takes MIDI input. The callers of the A366F4 transition manager are unread.
- **The source-context leads:**
  - A1EA68 and A01E24 don't read the MIDI word;
  - A562B8 builds the plug-in source context only for source type 2;
  - every MIDI-closure Sound is codec 0x00040001.
- **The velocity census** (ARM, 0x940000..0xAB0000; listed in the extractor report): velocity is only ever a
  zero/nonzero test, a filter shift, source 0x81 (nothing binds it), or the inherited velocity in E7b.
- **The banks have no RTPC keyed 0x81.**

## M9-012: corrected evidence

- **The loader** maps authored bits 2/3/4/5 → +0x47 bits 1/2/3/4 (0x009F6F74..0x009F7010).
- **The resolver** 9FAE18 (0x009FAE18..0x009FAEB4) walks to the first node with +0x47 bit2 (override), reads property
  0x2D (45) as the **root note**, and returns +0x47 bit3 (**enable**).
- **The only consumer** is CAkSound vt+0xAC 0x00A1DAB8: pitch += (key − root) × 100.0f, applied only when the channel is
  not 0xFF (0x00A1DAEC..0x00A1DB40).
- **Ordinary play** sets the channel to 0xFF (0x009AA734..0x009AA748, 0x00A2E540..0x00A2E598, 0x00A62A68..0x00A62AF4).
- **Shipped census:** 2886 objects across 6 banks.
  - **None sets authored bit3 or bit4.**
  - The only nonzero flag bytes are 0x24 on Layers 462443456 and 774902407, and 0x01 on three SFX Sounds.
