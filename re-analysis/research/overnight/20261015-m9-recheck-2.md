# Opus re-check 2 of the M9 modulators (M9-030, M9-031, M9-032, M9-033), 2026-10-15

- **Follows:** `research/overnight/20261015-ov38-41-check.md`.
- **Method:** a read-only cozmo-extractor answered the four RECOVERABLE_GAP records opened there, against libcozmoEngine.so
  (ARM, capstone with skipdata) and all six banks. Scratch scripts are in the session scratchpad `m9r2\`.
- **Adopted:** by the manager on 2026-10-15.

## Manager decisions

1. **The ADP-1 boundary.** An envelope's output is a modulation value, not PCM, the same as the LFO's. So its scalar and
   buffered evaluators, including the NEON 4-lane ramp emitters 0x009E5880..0x009E5E8C, are **exact**: their segment
   boundaries, their (x+2)&~3 rounding, their lane order, and the clamps.
2. **The early-release arithmetic** (d < the end of decay; 0x009E3B34..0x009E3CC8, 0x009E4CFC..0x009E4D2C) has no
   reachable trigger in shipped content. Only the unread case-5 producers of 0x00A01480 set such a deadline. It goes into a
   new RECOVERABLE_GAP record and isn't built.
3. **R and T come from the M6-018 policy:** 48000 Hz and 1024 frames. The phone's own values are HARDWARE_ONLY. At
   48000 the vibrato runs at 5.5 Hz.
4. **Status changes:**
   - **M9-030, M9-031, M9-032 and M9-033 move to IMPLEMENTATION_GAP.**
   - **Two new RECOVERABLE_GAP records:**
     - the envelope's remaining arithmetic;
     - the note-off dispatch's remaining callees, the holder look-ahead and pump order, and the note-on attachment flag.
5. **Whether the shipped note-off envelope 381606890 ever stops a voice is still open.** It depends on the second new
   record. M9-024's effect text mustn't claim that it does.
6. **M9-025's mode-0 build** waits only on an Opus check of the LFO initializer prefix 0x009D671C..0x009D7390, which is
   running.

## M9-033: the globals

- **R:** u32 at 0x0105243C, `.data` value 48000.
- **T:** u16 at 0x01052440, value 1024. Reached through GOT 0x01040068 / 0x01040058.
- **The only writers** are SetRate 0x00A1C784 and SetFrame 0x00A1C7E8, both called from platform init 0x00A57724.
- **R's value:**
  - PD.uSampleRate, if it's set;
  - otherwise min(native rate, 48000) (0x00A56E88..0x00A56EA4);
  - otherwise 48000 (0x00A578B4..0x00A578C8).
- **T's value:** AkInitSettings+0x20, rounded to the hardware buffer (0x00A577B8..0x00A57830). M6-018 owns this.
- **The LFO step uses a fixed 48000** (literal 0x009D7564). The phase advances by step·T per tick, so the real frequency
  is f·R/48000.
- **The LFO attack** is s32(f64(attack)·f64(R) ± 0.5) (0x009E2098..0x009E20D4).
- **The geometry threshold** is (48000/T)·0.25 = 11.71875 Hz at T = 1024.

## M9-032: byte +0x44

- **The ctor zeroes it** (0x009D7BFC envelope, 0x009D7C84 LFO).
- **The only other writer** is 0x009E730C, in 0x009E6EDC (single caller 0x00A11D6C, inside SubscribeRTPC 0x00A117C8, for
  rtpcType 2). The subscriber record holds +4 = paramID and +0x24 = subscriber type (0x00A119B4..0x00A11A14).
- **The rule:** +0x44 = 1 if type ≠ 1 and paramID ∈ {0, 7}. It's sticky.
- **Node bindings** subscribe with type 2 (0x009F7284..0x009F72EC → 0x009F1DE0 → 0x00A1A338; 0x00A1A374/0x00A1A380).
- **Shipped:**
  - **vibrato LFO 528935089 → param 2, so +0x44 = 0 and it's scalar** (it would be scalar anyway, since 5.5 ≤ 11.72);
  - envelope 381606890 → param 0, so +0x44 = 1;
  - vo_external: four with param 0, so 1; two with param 2, so 0.

## M9-030: envelope initializer and timing

- **E1, the defaults** (table 0x0108DAA8, 0x004DDF0C..0x004DDF94):

  | Index | Default |
  | --- | --- |
  | [0] | 0 |
  | [1] | 1 |
  | [9] | 100.0 |
  | [10] | 0.5 |
  | [11] | 200.0 |
  | [12] | 0.3 |
  | [13] | −1.0 |
  | [14] | 1000.0 |
  | [15] | 1 |

- **E2, the initializer** 0x009D5934(mod, P, **S**) (0x009D5934..0x009D671C).
  - **Each property is read in this order:** the blob, then the RTPC (if subscribed), then the range.
  - **The range:** min + f32(f64(LCG.hi >> 1)/2147483647.0 · f64(max − min)). The LCG is 0x5851F42D4C957F2D·s + 1, at
    0x0108D868. There's no draw when the span is 0. Only the range path clamps.
  - **The fields:**
    - P+0x1C = attack, in samples (rounded ±0.5);
    - P+0x28 = decay;
    - P+0x2C = release;
    - P+8: **0x7FFFFFFF if v13 < 0**, otherwise wrap32(decay + attack + s32(v13·R ± 0.5));
    - P+0x24 = v12/100;
    - P+0x20 = v10/100;
    - **P+0x18 = clamp(S+0x4C, 0, 1).**
- **E3:** S+0x38 = P+8 (0x009E27B0..0x009E27BC).
- **E4, the live setter** 0x009E1D8C..0x009E1F4C. Id 4 overwrites S+0x38, even a note-off deadline. No shipped envelope
  binds an RTPC, so it's unreached.
- **E5, the geometry** 0x009E1FB8..0x009E1FF4: buffered if +0x44 and min(attack, decay) < 2T. So 381606890 is buffered,
  and the vo_external envelopes are scalar.
- **E6, the initial value** (0x009E2000): if attack == 0, it's 1.0; if decay == 0 as well, it's the sustain. For
  381606890 that's 0.095.
- **E7, the input record** (0x009E2D18..0x009E2D8C). +0x14 selects the evaluator.
- **E8, the scalar evaluator** 0x009E387C..0x009E3DD4: the setup, the v0 shift (0x009E4CA8), the segments, and completion
  (0x009E3D94..0x009E3DCC).
- **E9, the buffered evaluator** 0x009E52F8..0x009E5808:
  - every length rounds with (x+2)&~3;
  - zeros are written before lr;
  - completion fills zeros (0x009E56FC..0x009E5800).

  The emitters are at 0x009E5880..0x009E5E8C. They're exact (decision 1), but their bodies aren't fully transcribed: see
  the new record.
- **E10, delivery** (0x009E8248, 0x009E82BC..0x009E82E8, 0x009E83C8..). The consumer of O+0xC is unread.

## M9-031: the note-off release

- **N1, the holder pump** 0x00A3EA3C..0x00A3EB24.
  - In the due frame, the release (0xA3E920) runs before propagation (0xA3E688).
  - Propagation runs in the **first** frame the holder is processed, even before it's due.
- **N2, PBI+0x34/+0x38** = {owner, pending deadline}, initialised to {0, 0xFFFFFFFF} (0x009E8728, from 0x009BC964).
  - The release writes +0x38 = offset only when there's no owner (0x00A3E98C); otherwise it calls 0x009E805C.
  - **The reader:** after a state attaches, 0x009DD8E8..0x009DD900 hands +0x38 over.
  - **The other writer:** 0x009BCF08, the case-5 path.
- **N3:** 0x009E805C walks the owner list, calling 0x009E21D0(S, offset). That sets S+0x38 = offset + S+0x3C, but only
  from the sentinel, and sets status 2.
- **N4, target vt+0x10:**
  - 0x00A70928 returns 0;
  - 0x00A3CE78 returns ctx+0xFC bit4, which is set only by a hard stop with offset 0xFFFFFFFF (0x00A3BDB8..0x00A3BDCC).
  - **When it's nonzero:** every entry becomes kind 3, with PBI+0x1F8 = −1 and A01280 (0x00A3E94C..0x00A3E96C).
- **N5, the kind dispatch** (0x00A3E9B4..0x00A3EA2C):
  - **kind 2** → PBI vt+0x1C. For the base PBI that's 0x009FF5D0: +0x1B8 = 1, then command 4, drained at 0x009D3B70 into
    voice vt+0x54. For the continuous PBI it's 0x00A6B2E8;
  - **kind 3** → +0x1F8 = offset, then A01280(…, offset == −1);
  - then the pending actions go to 0x009AB1F4.
- **N6, the kind:** 0x009EE174 / 0x009FAEC4; flags 0x009F6FE0..0x009F7010.
- **N7, propagation** 0x00A3E6A8..0x00A3E7DC:
  - first, the kind-1 nodes are played through 0x00A3DB48;
  - then the descriptor (start = E+0x18, scope 3) goes to node vt+0xA8 with &PBI+0x34.

**Per kind, at note-off, when the context isn't hard-stopped:**
1. **Every kind first gets the deadline handoff.**
2. **Kind 0** (get-in) plays on.
3. **Kind 1** (774902407) gets its voices created by the note-off.
4. **Kind 2** (462443456) gets a loop break, then envelope 381606890.
   - **Its deadline becomes finite** if the PBI had no owner, or if propagation ran in an earlier frame.
   - **It stays infinite** if both happen in the same frame **and** the PBI already had an owner. Whether the vibrato LFO
     attaches at note-on (params+0x128 bit2) is unread.
