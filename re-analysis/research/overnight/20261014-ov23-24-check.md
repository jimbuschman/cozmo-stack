## M10-014: BlockFilter and the gyro detector lifetime

- **B1, construction:**
  - **The BlockFilter:** `new(0x90)` (0x00510174..0x00510188). Its ctor (real entry **0x00619A2C**) sets:
    - +0 = Robot;
    - two blocks of five {0, 0xFFFFFFFF} pairs (+4..+0x53);
    - the tree header at +0x54;
    - memclr4(+0x60, 0x1D);
    - a vector at +0x80;
    - +0x8C = the interface.
  - **A null interface** skips the subscriptions.
  - **The subscriptions,** through slot +0x2C (Subscribe 0x00662750), bound to HandleGameEvents, in this tag order: E7,
    E5, E6, E9, EA, EB.
  - **The gyro detector:** `new(0x64)` (0x0050FE10..0x0050FE20), ctor 0x0052C53C..0x0052C566.
- **B2, BlockFilter retirement** (0x0051121A..0x00511250), in order:
  1. the vector dtor;
  2. the long-string free (+0x60/+0x68);
  3. the tree destroy (left, right, delete, with no value dtor);
  4. delete the filter;
  5. then read +0x26C, **before** clearing +0x44C.
- **B3, subscription release:** in reverse order (EB → E7), through the existing M1-046/M5-056 mechanism. The bind's
  destroy slots are 0x0061B778 (`bx lr`) and 0x0061B77A (delete). No handler is invoked.
- **B4, the detector's retirement** (0x00511418..0x00511424): null the owner, then delete. No report, save or disconnect.
- **B5, notes:**
  - a null handle in the container cleanup derefs at 0x004EF1BE (M1-034);
  - ~Robot's landing pad repeats the gyro null-and-delete at 0x00511752..0x0051175E, with no BlockFilter release. That
    path is exception-only (M1-034).

## M10-015: DetectGyroDrift and DetectBias

- **R1, the hook** (0x00512FB4..0x00512FCE): drift, then reload, then bias, then UpdateCliffRunningStats, with no null
  check.
  - **The gate:** UFRS's +0x29 time-sync exit (H1), then M4-019 C12.4/C13.2.
  - That includes **the GetLastStateWithFrameID failure** (0x0051307A..0x00513110): sErrorF
    `Robot.UpdateFullRobotState.GetLastPoseWithFrameIdError` "Failed to get last pose from history with frame ID=%d", the
    error flag, and **both detectors skipped**. Codex omitted it.
- **R2, DetectGyroDrift** (0x0052C568..0x0052C770), rows D1–D8:
  - **The gates:** latched (+4), then |z| ≤ 0x3E32B8C2, then Movement+9, then Cliff+5, then the head calibrated
    (R+0x314).
  - **The start:** frame, yaw, baseline/sum/min/max = z, ts, count = 1.
  - **A reject** when |base − z| > 0x3C8EFA35, or the frame differs.
  - **Accumulate** while < 0x1389 ms: max on `gt`, min on `mi`, sum = z + sum.
  - **Then:** d = Radians(start − current). Reject if |d| ≤ 0x3C0EFA35 or unordered.
  - **Report:** to_string(|d|·K) as "$data", then sWarningF `robot.detect_gyro_drift.drift_detected` "mean: %f, min: %f,
    max: %f". The mean is f32(f32(sum/count)·K). Then latch +4 = 1.
  - **Finally** +0x18 = 0.
- **R3, DetectBias** (0x0052C804..0x0052CB24), rows B1–B10:
  - **The high-pass:** hp = (a − prev + hp)·0x3F4CCCCD, with a = R+0x378.
  - **Status bit 0, or |hp| > 50:** reset (if started) and return.
  - **The window:** 0x1389 ms, with a signed `cmp #0x32`.
  - **Per axis** (x, y, z): the `ble`/sign/`ble`/`bpl` tests. Then:
    - sEvent `robot.detect_gyro_bias.bias_detected` with $data "min,max" (each roundf(f32(v·K)·1000));
    - sWarningF `RobotGyroDriftDetector.BiasDetected` "Gyro bias detected on %s axis (min=%.2f deg/sec, max=%.2f
      deg/sec)".
  - **The latch** doesn't break the loop.
  - **The filter:** raw·0x3D4CCCD0 + old·0x3F733333. min/max are chosen on `pl` (unordered keeps the old value).
  - **The reset:** +inf×3, 0×3, start 0, count 0.
  - **Kept as the original:** the ctor sets min = 0 and the reset sets max = 0.
  - ResetBiasDetector (0x0052CC20) has no caller.
- **Dependencies, cited and not re-owned:**
  - the yaw: GetAngleAroundZaxis (M11-065, R14);
  - Radians (M10-001 / NativeRadians);
  - GetPose's verifies;
  - the libm calls (roundf, sqrtf, signbit), per the libm policy;
  - the to_string(float) text: M11-083 (RECOVERABLE_GAP). That stays a visible MISSING until it settles.
- **R6, the inputs:**
  - Movement+9 = RobotState status bit 0 (MovementComponent::Update 0x0063E31A, earlier in UFRS);
  - Cliff+5 = the CliffEvent `detected` byte (HandleCliffEvent 0x005356C6..0x005356D4; the ctor zeroes it at
    0x00633FAC; found by a heuristic scan, so other writers aren't excluded);
  - R+0x2B0 (M11-053), R+0x314 (M4-004/M8-008).

## New M10 record: the raw IMU magnitude

At UFRS 0x005129C0..0x00512A1E:
- R+0x378 = vsqrt((x² + y²) + z²), using sqrtf when vsqrt gives NaN (`bvc`);
- R+0x37C is then the 0.05/0.95 smoothed value (M7-021).

M10-012 doesn't cover this computation.
