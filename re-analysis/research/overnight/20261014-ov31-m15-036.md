## Running dates and configuration boundary

IsExperimentRunning uses four date strings at Experiment+0x14/+0x20/+0x2C/+0x38. The generated shipped `unity/scripts/csharp/Anki.Util.AnkiLab/Experiment.cs` identifies these as start, stop, pause, resume; the native accesses and comparisons are 0x007EDD16..DD62. Let `S,E,P,R` be each parsed u32 result and `t` the u32 current time. With every subtraction performed modulo 2^32, the exact predicate is:

`S <= t && t <= (E-1) && (t <= (P-1) || t > (R-1))`.

Evaluation is ordered: parse S and return false if S>t; parse E and return false if E-1<t; parse P and save its comparison; parse R; OR the last two comparisons. There is no f32/f64 operation. Blank stop/pause values parse as zero, so subtracting one gives 0xFFFFFFFF; do not translate those cases into an ordinary signed negative date. Null experiment assertion at 0x007EDC94 is unreachable through RestoreActiveExperiment's checked pointer, but would continue toward a null access after logging if called independently; it is not a successful fallback.

EpochSecFromIso8601UTCDateString at 0x00831C68..1CAA returns 0 for empty string. Otherwise it zeroes a 0x2C-byte tm, calls imported strptime with `%Y-%m-%dT%T`, returns 0xFFFFFFFF if strptime returns null, else returns timegm's result bits. It does not check that the input ended at the returned pointer: the shipped trailing `Z` is not explicitly validated by this wrapper. strptime/timegm and system_clock are phone system-library boundaries; their implementations do not ship in this allowed binary. Their malformed-date/platform edge behavior is not invented here. Exact native branch/arithmetic semantics remain required; system-library behavior is the existing EQUIVALENT_IMPLEMENTATION allowance, not ADP-1.

AnkiLab constructor 0x007EBB34..BBC22 initializes enabled=true and empty definitions/assignment vectors, plus a signal object. CozmoExperiments constructor clears its two vectors +0x94/+0xA0 at 0x006A5594..9A. InitExperiments calls ShouldABTestingBeDisabled, XORs its bool with 1, and passes that to Enable at 0x006A5614..22.
