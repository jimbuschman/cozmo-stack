## Build rows (M8-022)

1. **The destination JSON:** null in the loader ctor (loader+0x220, 0x0051EF0E..0x0051EF16).
2. **The read in LoadRobotConfigs** (0x00522CE0..0x00522DBC):
   - scope 1; the function-static filename `config/engine/das_event_config.json` (0x00BE833B); into loader+0x220.
   - **On false:**
     - sErrorF `RobotDataLoader.DasEventConfigJsonNotFound` "DAS Event Json config file %s not found or failed to parse"
       (the relative filename);
     - `_errG`, break-on-error;
     - **no clear**, and it continues.
   - **readAsJson:** fopen "r". An open failure sets failbit and **still parses**, then returns the parse bool.
   - **A missing or empty file** leaves the root **null**:
     - Reader::parse never resets the root;
     - an EndOfStream token takes the default path, which writes only the offsets and adds "Syntax error: value, object
       or array expected." (0x008E082C..0x008E088C, 0x008E0A14..0x008E0B30);
     - the logs, in order: the DataPlatform error ("Failed to read [%s]"), the Unnamed debug "Json reader errors [%s]",
       then DasEventConfigJsonNotFound.
   - **A truncated object** keeps its partial members (`research/20261013-small-reads-2-check.md` item 4).
   - **Interfaces:** the readAsJson diagnostics are M5-051; the resource root is M3-062.
3. **The hand-off and ordering:**
   - CozmoEngine::Init passes (engine+0x18, the stored copy of the app config) and loader+0x220 (0x004EC9CA..0x004ECA1E);
   - RobotManager::Init, in order (0x0052E744..0x0052E776):
     1. steady_clock;
     2. MessageHandler vslot+8 (config, manager, [manager+0x18]);
     3. BroadcastAvailableAnimations;

     5. FirmwareUpdater::LoadHeader (M1-029; firmware update itself is out of scope).
