## Hierarchical dispatch and actual setter callers

9DBF78 reads modulator property0 through 9D7F3C (fallback at global108DAA8). Copies K; let scope be that property:

- scope<=0: no collapse.
- scope>=1: clear word14; if note byte K10 !=FF, clear playing word4.
- scope>=2: additionally clear words4/8 and set bytesC/10 toFF.
- scope>=3: additionally clear object word0.

It creates a separate scratch traversal key `{0,0,0,FF,FF,0}`. Root state (N24, present byte N28) is called when scope permits. Then descend N2C/count30: ordered object, playing, node, channel, note and extra leaves. Word wildcard0 or byte wildcardFF traverses every child in stored array order; a specific key uses unsigned binary search and only the exact found child. At each visited intermediate node, if present byte+8 is nonzero, call stored state+4 **before** descending. Leaf array entries stride8 `{state,keyWord}`; intermediate stride28, key+18, children+C/count10. Nonexistent keys return, not a fallback broadcast to unrelated states. Integer midpoint uses signed difference/round-toward-zero sequence, not overflow-prone `(lo+hi)/2`.

For the shipped LFO's scope1, ordinary object-level post `{object,0,0,FF,FF,0}` stays object-level and traverses that object's registered state descendants. Global post traverses all object children. This reaches states that already exist; no phase, attack origin, or note-on is synthesized.
