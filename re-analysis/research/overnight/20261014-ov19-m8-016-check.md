## New M10 record: the Hiccup strategy's dtor (D1)

ReactionTriggerStrategyHiccup's D1 (0x0061024C) is reached from M1 through the binding vector (0x005A47FE). It is
**live**: Hiccup is in the shipped reaction map.

1. now = BaseStationTimer::GetCurrentTimeStamp.
2. **If now > [this+0x2C]** (`bls` skips; the same test as HasHiccups): SendDasEvent(false). That computes:
   - elapsed = now − [this+0x54], or 0 when +0x54 == 0, as u32, through to_string;
   - sEventF `robot.hiccups.ended` with `{"$data", elapsed}`, format "%s", value "SELF_CURED".
3. Write 0 to the global `Anki::Cozmo::_this` (0x00610278).
4. Then the IReactionTriggerStrategy base (0x0060B6F4).

The event fires during ~BehaviorManager M1, before any activity is released.
