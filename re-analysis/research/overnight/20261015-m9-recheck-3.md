- **I5, the range:** no draw when the span == 0 (ordered). Otherwise:
  - the LCG at 0x0108D868 (s·0x5851F42D4C957F2D + 1);
  - r = f32(f64(s32(hi>>1))/2147483647.0·f64(span));
  - v = (min + r) + v.

  A NaN span draws.
- **The properties, in execution order** (which is also the RNG draw order):

  | Property | Clamp with a range | Without a range | Destination |
  | --- | --- | --- | --- |
  | Depth (2) | < 0 → 0; > 100 → 1.0; otherwise /100 | /100, **no clamp** (0x009D75E8 → 0x009D6914) | S+0x74 (0x009D6920) |
  | Waveform (5) | Not read | `vcvt.s32` (0x009D69F4) | S+0x80 |
  | Frequency (4) | < 0 → 0; > 20000 → 20000 | No clamp | S+0x84 |
  | PWM (7) | Like depth | /100 | S+0x8C |
  | Smoothing (6) | Like depth | /100 | S+0x88 |
  | Attack (3) | < 0 → 0; > FLT_MAX → FLT_MAX; NaN passes | No clamp | S+0x78 = vcvt.s32.f64(f64(R)·f64(v) ± 0.5) (0x009D71A8..0x009D720C) |

  The live setter rejects an index above 5 (0x009E2044), which is why phase is set at init only.
- **The join** at 0x009D7390, then the coefficient block:

  - **a NaN frequency** leaves q NaN;
