## Sequence and comparison conclusions

With an external interface and successful fresh initialization, the first call at 0x0052E76E sees only the constructor's procedural entry. GetNames filters that entry, so it invokes **zero AnimationAvailable messages, then EndOfMessage(0), then Debug**. A missing external interface suppresses all three parts. Initialization failures before manager Init do not reach this first broadcast.

The later normal loading-completion call is after the outer loading-thread join, which is after animation-file processing and inner joins. It traverses the current container's linked chain, removes only the procedural-name match, sends one AnimationAvailable per surviving entry, sends EndOfMessage(0), then Debug. Its caller subsequently sets engine state 3. This preserves the already-adopted order; it closes the fresh-first-call question without treating "container empty" as its premise.

The exact excluded bytes are `_PROCEDURAL_`, length 12. Changing case does not match. A name with those bytes plus a suffix, including a NUL suffix, has a different length and is not excluded. An embedded NUL does not end the counted comparison. The initializer's trailing terminator is not part of the compared length. This describes string comparison, not a claim that every asset/parser can create every such name.

The returned order is the container's linked hash-node order at enumeration time, copied into vector order. There is no sorting step. This is not a recovered fixed asset order or a claim of file insertion order: per-file worker scheduling and hash insertion/rehash affect the container. No fixed global list is asserted here.

EndOfMessage's only payload field is the byte identified as MessageType by the generated app code. Value zero comes from the native broadcast caller, not from the builder job. Corroborating generated definitions: `unity/scripts/csharp/Anki.Cozmo.ExternalInterface/EndOfMessage.cs` lines 8, 22, 57 and 68 declare the field, size 1, ReadByte and Write(byte); `MessageType.cs` lines 3–5 declares enum : byte and AnimationAvailable as its first value, zero. Native serialization confirms the same widths independently. Union Pack was read through its tag write, jump-table selection and selected EndOfMessage branch; unrelated union alternatives were not re-extracted.
