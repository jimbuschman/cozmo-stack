## M8-017: the compound action runtime

- **C1, the go-to-sleep factory** (0x0052CECA..0x0052CFA2): three triggers (0xD2, 0xD5, 0xD4), Parallel (0x9C bytes),
  lift preset 0 at 5.0. QueueAction(0, a, 0) (0x0052CE5E..0x0052CE6A).
- **C2, the ICompoundAction ctor** (0x0054E990..0x0054EA86):
  - the name "ICompoundAction", type −2, mask 0;
  - +0x98 = 0 and +0x99 = 1;
  - each null element in the ctor list gives Warning `ICompoundAction.NullActionPointer`;
  - each non-null element: AddAction(false, false);
  - slot +0x10 is UpdateInternal directly.
- **C3, the IActionRunner ctor** (0x0053FDB8..0x0053FE1C):
  - +8 = 0; +0x18 = 0x02000001; +0x1C tag 0xFF;
  - +0x55 = 0, +0x56 = 0, +0x57 = 1, +0x58 = 0.
- **C4, AddAction** (0x0054EC7C..0x0054EEAC):
  - the wrapper forwards its trailing bool, and only the function overload ignores it;
  - **the name is reassigned**, not appended: "[" for the first child, otherwise pop "]" and append "+"; then the child's
    name and "]";
  - +0x57 is copied to the child;
  - a predicate is stored only when the function is non-empty;
  - it returns a weak ref.
- **C5, the Sequential ctor** (0x0054F4F8..0x0054F54C): +0x9C = 0, +0xA0 = −1.0f, +0xA4 = front, +0xA8 = 1. Children are
  reset with true.
- **S1–S8, Sequential** (0x0054F70C..0x0054F992, 0x0054F5A0..0x0054F696, 0x0054F560..0x0054F59E):
  - the result table;
  - **a NaN deadline waits;**
  - c > 4 returns 0;
  - RunCallbacks, then ShouldIgnoreFailure;
  - the retry path;
  - **MoveToNextAction:**
    - the deadline is delay + now when delay > 0;
    - `bhi` waits while deadline > now or unordered;
    - one update of the next child;
    - only an exact R keeps the child;
    - 0 becomes R while children remain;
    - RunCallbacks runs only at the end.
- **P1–P5, Parallel** (0x0054FAB0..0x0054FBCC, Reset 0x0054EC56..0x0054EC7A). The retry goes through ICompoundAction::Reset:
  state = N, then each child's Reset(true).
- **D1–D4, completion and teardown:**
  - **StoreUnionAndDelete** (0x0054F050..0x0054F118), in order:
    1. the child's completion union;
    2. the map at +0x7C keyed by tag;
    3. Prep;
    4. the proxy (+0x98);
    5. delete (+0x99), or UnlockTracks (gated on +0x56 and state ≠ N).
  - **The dtor:** DeleteActions, then the maps, the list, and ~IActionRunner.
  - **DeleteActions' false-delete branch** relocks.

- **The AlreadyPrepped log (new, omitted by Codex).**
  - **Where it comes from:** IActionRunner::Update preps every result that isn't exactly R (0x00540626). PrepForCompletion
    (0x00540750..0x005407C0, M8-015) logs **Debug / Actions `IActionRunner.PrepForCompletion.AlreadyPrepped` "%s [%d]"**
    (name, tag) whenever +0x55 is already set, with no +0x57 gate.
  - **So a Debug line is emitted:**
    - for every completed child, at the compound's Store Prep (0x0054F0C0);
    - **twice** on Parallel's ignored-failure path (an explicit Prep at 0x0054FB3C, then again in Store);
    - in DeleteActions, for a failed child left in the list.
  - **The exception:** a child that failed the lock check (0x03000019) was never prepped, so its first Prep logs nothing.

## M8-019: RequestCurrentBehaviorEndImmediately

- **R1, the caller** (HandleRobotStopped, 0x00535432..0x00535486):
  - the cliff gate skips the request, Cancel and the broadcast together;
  - otherwise: request with "HandleRobotStopped", then Cancel(−1), then broadcast RobotStopped (empty).

  This is an interface to M4-019 H4.
- **R2:** an Info on channel "Behaviors", key `BehaviorManager.RequestCurrentBehaviorEndImmediately`, "Forcing current
  behavior to stop: %s", with **no guard before it** (not even the init byte).
- **R3:** SwitchToBehaviorBase({null, null, 0x16}), result discarded. Then release the resume control (+0x14), then the
  current control (+0xC) (0x005A3930..0x005A39A6).
- **Owned elsewhere:**
  - **M8-012:** R4–R7, T1–T4, E1–E5. The SendDas body (0x005A22B4..0x005A24AC) is read; EnsureRequestGameIsClear isn't.
    E3 is triggers 0x15 Count / 0x16 NoneTrigger. Transition messages use tags 0x87 and 0x88; id 0xB2 is "Wait".
  - **M8-001:** S1–S3, IBehavior::Stop:
    - **StopActing's vtable+0x80 is always ScoredActingStateChanged** (0x005BF045), which stores 0 to +0x104 and ignores
      its bool. Every Stop with a behaviour running therefore zeroes +0x104;
    - the base StopInternal (+0x54) is `bx lr`. There are 61 concrete overrides, still under their behaviour records;
    - +0x30 is stored from an f32 time.
  - **M8-009:** S5, undo in key order.
  - **M8-011:** S4 and the helper chain.

## Contradicted records

  from StopActing (0x005BD35A), StartActing (0x005BDB54) and HandleActionComplete (0x005BE200), and it always stores 0.
- **M8-017's evidence:**
  - "the trailing boolean is never loaded": the wrapper loads it;

- **M8-009's evidence prose** ("most-recent-first"): stale. The order is by key.
- **M8-012:** cites 0x005A1E6A as SwitchToBehaviorBase. The entry is 0x005A1E20; 0x005A1E6A is a call site.
- **M4-028** is too weak: "exact child initialization, locking, stop and completion must be verified". That is now
  M8-017 and M8-015.
