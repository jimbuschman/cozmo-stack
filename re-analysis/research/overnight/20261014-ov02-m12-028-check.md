## Corrections

- **The free check's family filter.** {2 LightCube, 1 Block} goes to filter+0x3C, the **allowed** families. It isn't an
  excluded set. This agrees with M11-004.
  - The +0 ID set is the ignore set (it holds the static block).
  - +0x6C = 0 means no latest-only predicate; +0x6D = 0 means current origin only.
  - **Net effect:** the free check looks only at LightCube/Block objects in the current origin, other than the static
    block.
  - With bool 0, the query returns the first-encountered strict minimum. The free check uses only null versus non-null.
- **T7:** a second delegation in the top loop **replaces** the first. It isn't a repeated delegate.
  - SmartDelegateToHelper warns "Attempted to start a handler while handle already running, stopping running helper",
    then calls StopHelperWithoutCallback (0x005BEBA4..0x005BEBE8).
  - DelegateToHelper overwrites both callbacks (0x0056DAE4..0x0056DAF8) before its stack-empty check (which fails with
    Info "<name>SmartDelegateToHelper.Failed" "Failed to delegate to helper").
  - Whether this can happen depends on whether two PyramidBase entries can both contain A and B. That's unread.
- **The callback order** (fn1 = success, fn2 = failure) is proved by BehaviorHelperComponent:
  - DelegateToHelper stores +0x10 and +0x28 (0x0056DAE8..0x0056DAF8);
  - UpdateActiveHelper calls +0x10 on status 2 and +0x28 on status 0 (0x0056E10E..0x0056E12E).
- **IsAtPreActionPoseWithVisualVerification** returns an ActionResult, where 0 means "at pose" (M12-031).
