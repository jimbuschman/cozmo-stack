## Build rows

1. **MovementComponent::MoveHeadToAngle** (0x006407CC..0x0064088A):
   - the id comes from `ldrb [MC+8]; adds #1; strb` (M4-005's shared counter); when an output pointer is given, the low
     byte is written to it;
   - the message struct is angle, speed, accel, duration, id (+0x10), with union tag 0x37 (0x007A861E..0x007A862E);
   - Pack writes 4+4+4+4+1 bytes (0x007A2670..0x007A26C8);
   - SendMessage(reliable 1, hot 0) returns the raw result, then ClearCurrent.
2. **MovementComponent::TurnInPlace** (0x00640898..0x0064098E): the same id rule, with tag 0x39 (0x007A8768..0x007A8778).
   - **Pack** writes 4×4, then u16 halfRevs (`strh` keeps the low 16 bits), then `Write<bool>` isAbsolute, then u8 id:
     20 bytes (0x007A296A..0x007A29DA).
3. **TrackLayerComponent:**
   - **AddEyeShift** (0x0064F3C8..0x0064F498), with GenerateEyeShift's argument order x, y, xMax, yMax, up, down, outer,
     duration, frame:
     - **a nonzero id:** AddToPersistentLayer;
     - **otherwise:** a default frame first, only when duration ≠ 0, then AddPersistentLayer, and the id is stored
       (0x0064F476).
   - **RemoveEyeShift** (0x0064F4F4) goes straight to RemovePersistentLayer, with no zero guard.
   - **RemoveKeepFaceAlive** (0x0064F2EC → 0x0058CFAC..0x0058CFC0) checks the +0x1C guard, removes the layer, then clears
     +0x1C.
4. **TurnInPlaceAction::Init's eye block** (M13-022, 0x00546144..0x00546298):
   - **halfRevs** = (+0xC0 == 0) ? `vcvt.u32.f32(floorf(|vdiv.f32(+0xA4, π)|))` : 0, and isAbsolute = (+0xC0 ≠ 0);
   - **the arguments:** angle +0x9C, speed +0xC4, accel +0xC8, tol +0xB0, and &+0xDA;
   - **the failure path** gives 0x03000016;
   - **the eye-shift amount:** +0xAC = |unclipped a|·0.5, then (tanf(c)·17.52f)·1.2307692f, all f32. NaN is kept by `ge`
     and passed by `hi`;
   - **the eye dart:** "TurnInPlaceEyeDart" with (y = 0, 132, 64.0f, 128.0f, 0x3F8CCCCD, 0x3F59999A, 0x3DCCCCCD).
5. **TurnInPlaceAction::CheckIfDone** (M13-022, 0x0054642C..0x0054689A):
   - **The wait for the ack:** a u16 counter in .data at 0x01051024 (starts at 10). It logs "Actions"
     "TurnInPlaceAction.CheckIfDone.WaitingForAck" "[%d] ActionID: %d" with (+0x60, +0xDA).
   - **The yaw** comes from Robot::GetPose 0x004EA398, with its two verify checks.
   - **The traversed angle:** delta = Radians operator− (f32 subtract, then rescale; 0x0084CA18), added to the old +0xA8
     with `vadd.f32`.
   - **IsBodyInPosition** (0x00546374..0x00546422):
     - `bpl` is taken when d ≥ π or unordered;
     - the tolerance is tol + 1e-5;
     - IsNear rescales only `this` and uses a strict `mi`.
   - **RemovingEyeShift:** `ble` skips on equal or unordered. The log has the format "Currently at %.1fdeg, on the way to
     %.1fdeg (traversed %.1fdeg)", then RemoveEyeShift(robot+0xC0, id, 0x63).
   - **InPosition:** its log reports degrees(+0xB8) and degrees(+0xB0).
