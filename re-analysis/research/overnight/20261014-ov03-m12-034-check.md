## Corrections and additions

- **Ramp is unreachable.**
  - The C1 ctor's only caller is Ramp::CloneType, which needs an existing Ramp.
  - The C2 ctor has no caller.
  - The vtable GOT slot is referenced only inside the ctor.
  - No other shipped .so names the ctor.

  So Ramp::IsPreActionPoseValid, and its root-parent crash at 0x008452BA, are dead code. **It is read, and not built.**
- **Trigger +0xF0 decides whether C5 does anything:**

  | Action | +0xF0 | Address |
  | --- | --- | --- |
  | IDockAction default | 0x23F (Count) | 0x005503D6 |
  | PickupObjectAction | 0x207 SoundOnlyLiftEffortPickup | 0x005536EE |
  | PlaceRelObjectAction, place-on-ground arg = 0 | 0x208 SoundOnlyLiftEffortPlaceHigh | 0x00554C68..0x00554C94 |
  | PlaceRelObjectAction, place-on-ground arg ≠ 0 | 0x209 SoundOnlyLiftEffortPlaceLow | 0x00554C68..0x00554C94 |
  | RollObjectAction | 0x20A SoundOnlyLiftEffortPlaceRoll | 0x005565E0 |

  - Align, PopAWheelie and FacePlant keep the Count default, so C5 returns at once for them.
  - SetPostDockLiftMovingAnimation's only caller (0x0055C680) is dead.
- **Re-Init replaces the C5 and DA handles; it doesn't append them** (0x0055177A..0x00551784). Only the E2G handle is
  appended.
  - This is a lead against M12-017's note that "each IDockAction registration now appends a retained DA subscriber at
    Init".
  - It matters only if one action's Init runs twice (M2-023's re-Init rows).
- **M12-039's authority wording** "Rotation3d::GetAngleAround…" should read RotationMatrix3d. Its own `unresolved` already
  says so.
