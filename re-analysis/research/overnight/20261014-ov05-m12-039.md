## Axis selection and all angle arms

The row-major matrix consists of nine f32 entries. GetRotatedParentAxis<'Z'> reads `M20,M21,M22` by indexed access (`0x005507B2..0x005507C8`). Start with X's component and code +1 iff x>0, otherwise -1. Replace with Y only if `abs(y)>abs(x)`, assigning +2 iff y>0 else -2. Replace with Z only if `abs(z)>abs(selected)`, assigning +3 iff z>0 else -3. All tests and absolute values are f32. Ties retain the earlier axis, X before Y before Z; unordered comparisons do not replace it. Zero takes the negative sign. An optional output pointer receives the signed selected component; every call in this calculation passes null (`0x005507C8..0x00550856`).

Helper `0x00550858` selects an axis again from the **composed** matrix. It does not reuse the earlier carried/target axis. Its seven-byte table at `0x00550872` is `04 0A 10 1A 1A 1F 24`; index is unsigned `(axis+3)`, with out-of-range going to +X. Arms: -3→negative Z, -2→negative Y, -1→negative X, 0/+1/default→positive X, +2→positive Y, +3→positive Z. Negative means invoke Radians unary minus after getting the axis angle, including its rescale (`0x0055087A..0x005508C6`). No direct logging occurs in the axis selector, helper or matrix-angle functions.

In the following specification, every multiplication and addition is a separate **f32** operation, not a fused operation or a double expression rounded only at the end. `atan2f(y,x)` is the imported phone libm function. The branch selects the first pair only for an **ordered strict greater-than**; equality and NaN select the second.

| Function | Evaluation order before the comparison | First pair if left > right | Otherwise, including unordered | Native body |
|---|---|---|---|---|
| Matrix X | Load a=M11,b=M12,c=M21,d=M22. Compute a*a, b*b, c*c, d*d. Compute right=(b*b)+(d*d), then left=(a*a)+(c*c). | atan2f(c,a) | atan2f(sign-bit-flipped b,d) | `0x0084B370..0x0084B3CA` |
| Matrix Y | Load a=M00,b=M02,c=M20,d=M22. Compute a*a, b*b, c*c, d*d. Compute right=(b*b)+(d*d), then left=(c*c)+(a*a). | atan2f(sign-bit-flipped c,a) | atan2f(b,d) | `0x0084B3CA..0x0084B424` |
| Matrix Z | Load a=M00,b=M01,c=M10,d=M11. Compute a*a, b*b, c*c, d*d. Compute right=(b*b)+(d*d), then left=(c*c)+(a*a). | atan2f(c,a) | atan2f(sign-bit-flipped b,d) | `0x0084B424..0x0084B47E` |

Negation of the atan2 input is an integer `eor #0x80000000`, preserving signed-zero bit behavior; the branch is `ble` after VFP comparison (`0x0084B3A4`, `0x0084B3FE`, `0x0084B458`). Each atan2f result is passed to Radians(float), which sets its rescale flag to 1 and calls rescale (`0x0084C832..0x0084C846`). There is no epsilon or normalization in these matrix-angle bodies themselves.

Radians rescale (`0x0084C87C..0x0084C936`) leaves **(-pi_f,+pi_f]** unchanged, where pi_f bits are `0x40490FDB`. Exactly -pi_f becomes +pi_f. Outside that interval with abs(value)<10f, add +2pi_f (`0x40C90FDB`) while value<=-pi_f, then add -2pi_f (`0xC0C90FDB`) while value>+pi_f, with a rounding at every f32 addition. The other branch, also selected for NaN, performs f32 divide by 2pi_f, f32 add -0.5, imported ceilf, VFP float→signed32 conversion, signed32→float conversion, f32 multiply by 2pi_f, then f32 subtraction from the original value. The port must preserve that conversion behavior, not substitute `%`. Unary minus (`0x0084CB04..0x0084CB28`) uses vneg.f32, then rescales when the source flag is set; all angle functions here set that flag. Consequently the negative arm also maps a negated +pi_f back to +pi_f. Signed zero is not changed by an in-range rescale.

The surrounding transform path is not a double-matrix shortcut: M11-065 owns f64 unit-quaternion composition and normalization, f32 translation/point rotation, and f64-product-to-f32 matrix generation followed by matrix renormalization. M11-066 owns the actual parent-tree traversal and logs. M11-067 owns Rodrigues and pose-copy semantics. This call uses the **matrix** angle formulas after those operations. The independently checked PreMultiplyBy at `0x0084AC78..0x0084ACA6` copies the argument quaternion, multiplies that copy by the original receiver, and writes it back; PreComposeWith rotates the old f32 translation by the argument rotation and adds argument translation in x,y,z order (`0x0084BA34..0x0084BA7A`).
