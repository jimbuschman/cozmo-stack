## Build rows (M11-047)

- **a, the neighbour table and descent:**
  - **The table:** direction normals d0 = (1,0), d1 = (0,−1), d2 = (−1,0), d3 = (0,1) (Y table 0x0068C56C, X table
    0x0068C57C). An invalid direction gives (0,0,0). The names are N, E, S, W, Invalid.
  - **FindSingleNeighbor** (0x006881B4..0x00688214):
    - quadrant 4 gives null;
    - it looks up 0x01051064 at q·8 + d·2;
    - **byte1 ≠ 0:** the parent's child[byte0], or null if the parent has no children;
    - **byte1 == 0:** recurse; if the result has children take child[byte0], keeping the result when that child is null.
  - **AddSmallestDescendants** (0x00688104..0x006881B0):
    - a leaf pushes itself;
    - the pairs are (0,1), (1,3), (3,2), (2,0) when clock == 0, otherwise (1,0), (3,1), (2,3), (0,2);
    - d > 3 indexes 0xFF.
  - **AddSmallestNeighbors** (0x00688220..0x0068824E): (d+2) with a signed remainder; clock' = (clock == 0); it only
    appends.
- **b, the combination cache:**
  - **The key:** u64, high word = seed type, low word = flags, compared as unsigned 64-bit.
  - **The node:** 0x28 bytes; dirty +0x18 = 1; the vector at +0x1C.
  - **Refresh** runs FindBorders only when the entry is dirty.
  - **InvalidateBorders** (0x0068923A..0x0068928A): in key order, set dirty = 1 **and empty the waypoint vector**. It
    runs on every type change, but not on a same-type ForceSet.
- **c, CheckedDirectionInfo:**
  - ctor {0, 0, 0, −1}, ×4, in a 0x4C node;
  - Init only when size == 0;
  - MarkChecked decrements once;
  - AreAllDirectionsComplete checks +0xC, +0x1C, +0x2C, +0x3C;
  - no bounds checks (0x0068A9F4..0x0068AB94, 0x0068C244..0x0068C286).
- **d, the FindBorders state machine** (0x0068AB98..0x0068B096):
  - **Init:**
    - proc+0x20 = &combination;
    - clear the vector, keeping its capacity;
    - proc+0x28 = 1;
    - the checked map with mlf 1.0f, reserve(1 << root.level);
    - the seeds come from typeSets[seedType] through `operator[]`, which creates the set.
  - **The first-contact search:**
    - the bit is marked **before** the type test;
    - acceptance is flag & mask;
    - a miss rotates (d+1)&3, with idx = 0;
    - there's no same-type test.
  - **The first emission:** AddBorderWaypoint(seed, nb, d), +0xD = 1, fp = idx+1.
  - **Side exhaustion:** rotate again, with no skip for remaining == 0.
  - **The walk:**
    - **A same-type crossing** is tested first:
      - d = (d+2)%4;
      - rebuild the neighbours, then search them linearly for the old current; if it's not found, fp = count;
      - mark the reverse contact on N;
      - current = N;
      - continue.

      The crossing appends no waypoint.
    - **A masked new contact:** append (current, N, d), mark, continue.
    - **A masked checked contact:**
      - an empty vector does nothing;
      - if the last +0xC is 0, append a duplicate and set +0xC = 1;
      - **then end the walk.**
    - **An unmasked contact:** if the vector isn't empty, set the last +0xC = 1; mark; continue, even if the bit was
      already set.
  - **Finish:**
    - while any of the seed's counts ≠ 0, restart at d0/idx0;
    - then dirty = 0 and proc+0x20 = null;
    - proc+0x28 isn't reset;
    - no logs.
- **e, the waypoints** (0x0068A998..0x0068A9F2, 0x0068BC90..0x0068BD62):
  - **The fast path:** stm, then strh 0.
  - **The slow path:** +0xC from the bool, +0xD = 0, capacity max(2·cap, n+1).
  - **FinishBorder.**
- **f, FillBorder** (0x00689FAC..0x0068A2D6):
  - **The snapshot:** `from` is deduplicated through a local murmur-hashed set; the raw f32 x/y come from node+0xC and
    node+0x10.
  - **The insert:** the root is re-read for each point; Polygon(1 point) → FastPolygon → QuadTreeNode::Insert, with the
    result ignored.
  - **The static profiler:**
    - the key is "QuadTreeProcessor.FillBorder";
    - the print interval is 5000, written on every call;
    - it prints only when the time since the last print > interval, and updates lastPrint before printing;
    - DAS output is off (−1).
- **g, FillBorderInternal** (0x006813B0..0x00681400, MemoryMap vt+0x4C): map+8 = 1. The live call uses seed 9, out 10,
  and the mask 0x4F8 (from table 0x00C87675), with ts = GetLastImageTimeStamp.
- **h** (M11-017): the live call happens only when the frame's border-segment vector is non-empty (0x00680290,
  0x00680310 → 0x006803AC).
- **i** (M11-045): the type sets and the pointer hash container:
  - mask 0x7C8;
  - the murmur2 pointer hash (0x005198E0);
  - insert with mlf 1.0f, where NaN means no growth;
  - rehash: a request of 1 becomes 2; a non-power-of-two goes through __next_prime; it throws at ≥ 0x40000000;
  - erase unlinks while keeping the others' order, and never shrinks.

## Crash points (M1-034 standing rule; only with malformed topology)

- **A null-content `ldrb [content,#4]`:** 0x0068AD2C, 0x0068AE4C, 0x0068AE62, 0x0068AF30 (FindBorders) and 0x00689444
  (HasBorderSeed).
- **A null parent:** 0x006881E4.
- **d > 3:** 0x00688190.
- **A reverse contact that isn't found:** 0x0068AF10.
