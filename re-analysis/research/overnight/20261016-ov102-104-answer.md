## M15-064 (new): FeedingSoundEffectManager and E2G 149 FeedingSFXStageUpdate (IMPLEMENTATION_GAP)

**A1, NotifyChargeStateChange** (0x0056EA4C..0x0056EB20, 0x0056EB28..0x0056EB6A, 0x0056EB90..0x0056EBC0):

**Fields:**
- +4: last ID (−1);
- +8: count (0);
- +0xC: last change (4).

**Behaviour:**
- **The same cube:** broadcast E2G 149 FeedingSFXStageUpdate{u8 stage = c, f32 chargePercentage = count·0.0625f}, then
  store the ID, count and c.
- **A different cube:**
  - c == 0 and last ≠ 1 → ResetChargeSound, then store;
  - c == 1 and last ≠ 1 → ResetChargeSound, then broadcast {1, count/16} **count times**, then store;
  - c == 1 and last == 1 → store only if the stored count < count;
