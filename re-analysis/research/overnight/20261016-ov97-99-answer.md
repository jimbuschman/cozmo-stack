# Opus answers to OV97, OV98 and OV99 (M6-037, M6-038, M6-039), 2026-10-16

- **Method:** a read-only Opus cozmo-extractor, against libcozmoEngine.so: ARM (literals at pc+8) for Wwise, Thumb for
  Anki; capstone with skipdata; no decompiler output. "No static caller" means three scans came back empty: ARM b/bl,
  Thumb bl/blx, and a raw 32-bit literal search. Scripts are in the session scratchpad `r9799\`.
- **Adopted:** by the manager on 2026-10-16. An Opus answer is the checked evidence; no second pass.
- **New records:**
  - M6-040, the bus remainder (RECOVERABLE_GAP);
  - M6-041, the music stop tree (RECOVERABLE_GAP);
  - M6-042, Term-time notifications and the engine destructor order (RECOVERABLE_GAP; a candidate M1-034 point);
  - M6-043, the remaining Term-path transitive callees and stream bodies (RECOVERABLE_GAP);
  - M6-044, the JavaVM input to Wwise Term (COMPATIBILITY_POLICY).

## M6-032: which shutdown steps stop the robot-bus voices

- **~CozmoAudioController** (0x5946F0..0x594716) destroys its two maps, then ~AudioEngineController (0x8D1C1C). Nothing
  calls into Wwise before 0x8D8048 → 0x8D8068 → Term.
- **~RobotAudioClient** (0x599A6C) calls AbortAnimation only if an animation is current. That path ends at 0x9A6064,
  which posts message 0x19 asynchronously, and T1 discards it if Term's thread stop comes first (0x9ACF44). The five
  UnregisterRobotAudioBuffer calls make no Wwise call.
- **The order of the two destructors is unread** (M6-042).
- **At Term,** A40D44 destroys every voice, then the bus loop (0xA40DEC..0xA40E38) destroys every remaining bus.

So nothing before Term reliably stops robot-bus voices. Reaching the post-map-death destroy callback is likely whenever
robot audio is playing at shutdown. It remains HARDWARE_ONLY.
