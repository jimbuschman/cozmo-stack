## Inherited pose diagnostics and state outside the owner

Search linked slots by equality with handle+8, stop at sentinel, and only if found call the specialization's remove routine. A repeated reset after removal finds no slot. No signal emission, user event invocation or message send occurs here.

All eight ordinary handle destructors reset their vtable and release nonnull weak owner+0x10; deleting destructors do that and free the handle. No log or message in these bodies.

Each remove routine first destroys function storage at slot+0x18: inline callable (storage==slot+8) uses callable virtual+0x10; heap callable uses virtual+0x14; empty skips.
