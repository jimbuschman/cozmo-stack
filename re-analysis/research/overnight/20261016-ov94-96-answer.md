## Corrections

- **M9-005 is contradicted:**
  - the header tempo **is read** at runtime (0x00A3EEF8..0x00A3EF6C);
  - it is replaced only when A3C8F0 returns nonzero (an ancestor with +0x7C bit2, M9-044);
  - the container is not SMF.
- **M9-024:** Case A/B is a per-note runtime outcome of the M9-042 mechanism, so its effect stays a disjunction.
- **M9-035:** the static pitch at recompute depends on whether the note's LFO state exists yet (M9-045 P4).
