## OV37: M6-029, confirmed and corrected

- **The gate:**
  - `cmp r5,#0` at 0x004EA84C tests **DataPlatform*** (`mov r5,r1` at 0x004EA73C), not the external interface;
  - production passes both (0x004EB286..0x004EB28C).
- **~CozmoContext's order** (0x004EABBA..0x004EAC14).
- **The multiplexer dtor** (0x008DEB08..0x008DEB4E; 0x008DF6E0..0x008DF758).
- **The derived controller** (0x005946F0..0x0059472C). It doesn't delete the RobotAudioBuffer values.
- **The base controller** (0x008D1C1C..0x008D1C9E; GC 0x008D1CA4..0x008D1D0E).
- **The plug-in holders** (0x008DC124..0x008DC178; 0x008DD552..0x008DD59A; 0x008DB2AC..0x008DB2FE).
- **Both input types:**
  - AudioUnityInput: registered once (0x004EDC8A..0x004EDC96); dtor 0x00591BA0..0x00591BBE;
  - AudioEngineInput: per robot (0x004ED260..0x004ED26C); dtor 0x00590AA0..0x00590AE6.

  There's no UnregisterInput.
- **The runtime sequence** (0x008D8048..0x008D80A2), and the stream-hook wrappers (0x008D80AC..0x008D80D6;
  0x008D98F2..0x008D9932; 0x008D6C38..0x008D6CC4).
- **The Wwise Term head** (0x0099DCEC..0x0099DE00). A null bus is skipped (0x00A40DFC). The tail 0x0099DE00..0x0099E318
  wasn't re-read.
- **Omitted, the Hijack destroy path:**
  1. bus teardown 0x00A4EED8 → 0x00A4ECE4, then A4E7CC per FX slot, which calls vt+8;
  2. Hijack Term 0x008DBDF9 (fx+0xC0 when [fx+0xD0] is set);
  3. the destroy lambda 0x00595FE0, which logs Info "CozmoAudioController.HijackAudioPlugin" "Destroy Plugin id: %d
     callback";
  4. it then finds in **controller+0x78**, already destroyed at 0x0059470C, and on a hit calls CloseAudioBuffer.

  Whether a Hijack FX is still live at Term is unread.
- **M1-034 points:** 0x008D9914 (a write to address 4), 0x00A40D84/0x00A40D88, 0x008D8062 → terminate, and the
  candidate at 0x00596028..0x00596030.
- **Not re-checked:** OV37 rows 7, 19, 20 and 22; 0x009D3EC4..0x009D3F38; 0x0096091C.
