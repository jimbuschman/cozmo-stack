## Build rows (M13-029)

- **A, PathComponent::Abort** (0x00649100..0x006491BA), in this order:
  1. **The Info log:** channel `Planner`, key `PathComponent.Abort`, format "Aborting from status '%s'". The status name
     comes from the table at 0x0102F610, unchecked.
  2. **Cancel the planner:** if +0x20 is non-null, call its slot +0x10 (result ignored); **then** +0x47 = 0.
  3. **Release the selected-goal shared_ptr:** +0x30/+0x34 are zeroed, then the old control block is released.
  4. **ClearPath,** keeping its result as the return value.
  5. **Reload the status:** if it's 0..4 (an unsigned compare), call the setter with 4 when (1 << s) & 0x13 is set,
     otherwise 5.
  6. **+0x46 = 0.**
  7. **Pop the callback vector:** store `end − 12` **before** calling slot 0.

  UnknownOriginID is the constant 0 (.rodata 0x00C97B20).
- **C, ClearPath** (0x00649220..0x0064929E):
  1. ErasePath. It builds only a local MessageViz (tag 0x21) and sends nothing (0x006BFACE..0x006BFAE2).
  2. The doler's Path::Clear, then +0xFC = 0xFFFF and +0xF8 = 0.
  3. +0x40 = 0xFF, and the u32 word at 0x0084BCA8 is copied to +0x3C as is.
  4. EngineToRobot tag 0x3C with the u16, then SendMessage(reliable 1, hot 0), then ClearCurrent. It returns the raw
     result.
- **D3–D7, the planners:**
  - **The cancel slots:** each installed planner's slot +0x10 is the base `bx lr` (0x004F1A06), except the lattice
    planner's StopPlanning (0x004FD1A2..0x004FD1CC).
  - **Destruction:** `__on_zero_shared` (0x0064B252, 0x0064B28E, 0x0064B306) runs the D0s, and each D0 tail-calls delete.
  - **The base cleanup** is 0x004F19AC..0x004F19F0. Path's dtor (0x0085C7B4) uses `delete[]`, then zeroes the pointer.
- **W4–W7, the lattice destruction:**
  - 0x004FD154..0x004FD18E;
  - DestroyThread (0x005018E8..0x00501A04):
    1. F1 = 1;
    2. lock and unlock E8, then notify_all on E4;
    3. Debug `LatticePlanner.DestroyThread.Join` with an empty format;
    4. join;
    5. Debug `LatticePlanner.DestroyThread.Joined`;
    6. destroy and delete the thread; DC = 0.
  - Then the condition_variable_any's own destruction (it holds its shared_ptr<mutex> at E8/EC);
  - 0x008583D4..0x00858428 and 0x00851DDC..0x00851E12.
- **T, teardown** (0x0051111E..0x00511120, 0x0051127E..0x00511288, 0x00648FFC..0x00649080):
  - AbortAll runs first. Robot+0x5C is zeroed before the PathComponent dtor runs.
  - The dtor calls Abort again. The vector dtor decrements first, then calls slot 0.
  - The object at +0 is the SpeedChooser.
  - **Exactly two ClearPath send attempts on normal teardown:** AbortAll's and the dtor's. The action dtors between
    them (0x00511146/0x00511156) see a status of 4 or 5, so IsActive is false and they don't abort again.
- **The selected-goal byte:** the DriveToPoseAction ctor allocates it (0x0055A29E..0x0055A2AE), Init passes a copy
  (0x0055A976..0x0055A998), and its control block deletes it (0x0055DCBE). The action keeps its own reference, so
  Abort's release never frees it while the action is alive. These are M12-023's and M12-032's; M13-029 only releases it.
