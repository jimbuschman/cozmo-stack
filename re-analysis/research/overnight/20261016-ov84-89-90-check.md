# Opus check of OV84, OV89 and OV90 (M6-034, M6-035, M6-036), 2026-10-16

- **Checked:** `research/overnight/20261015-ov84-m6-034.md` (Codex), `20261016-ov89-m6-035.md` (Nemotron) and
  `20261016-ov90-m6-036.md` (Nemotron), against libcozmoEngine.so (ARM, capstone with skipdata, literals at pc+8).
  Read-only cozmo-extractor. Tooling is in the session scratchpad `chkm6\`.
- **Adopted:** by the manager on 2026-10-16.
- **Results:**
  - **OV84 (Codex)** is reliable, with one count error and one omitted trap.
  - **OV89 (Nemotron)** is wrong on its central claim: 0xA4F36C **does** have a caller. The sweep conditions are inverted.
  - **OV90 (Nemotron)** is unusable as evidence. Three of its "EXACT_SOURCE" rows are wrong, and "0x008D9E54 isn't code"
    is wrong too.
  - **The rows below replace OV89's and OV90's rows.**

## Manager decisions

1. **M6-035 moves to IMPLEMENTATION_GAP** for rows 1, 3 and 5–8. Setter 2 (0xA4F544) has no static caller: it's
   recorded, not built. **A new RECOVERABLE_GAP:** the other bus-destroy contexts, the setters of +0x1CC bit0, and the
   bodies of 0xA4FEF8, 0x9E9E78 and 0x9E9F08.
2. **M6-032 stays reachable.** The robot bus survives map death whenever an input is connected, it was mixed into in the
   last frame, or +0x1CC bit0 is set. Whether it actually fires stays HARDWARE_ONLY.
3. **M6-034 moves to IMPLEMENTATION_GAP** with the corrections below.
   - **New M1-034 point:** 0x9A7B80.
   - **A new RECOVERABLE_GAP:**
     - H3's music-engine Term (0x97D834 → 0x97D528);
     - which receiver variant the init settings byte +0x3C selects (the path from Anki's settings at 0x8D8188..0x8D8192
       to Init 0x8D81FC);
     - OV84's unread callees.
4. **M6-036 moves to IMPLEMENTATION_GAP:**
   - blocking Term;
   - 0x96D624's non-cache path;
   - 0xA7AA48 and 0xA7AEC4;
   - the device dtor chain;
   - the cache-path loop structure, with its frees and cond signal.

   **The buddy-coalesce arithmetic in stream-cache mode isn't built.** It writes allocator free lists that 0x96D694
   destroys at once, and nothing reads them, so it has no observable output: memory only, like the M11-090 allocator
   residue. **A new RECOVERABLE_GAP:** the stream class behind 0x8D9E54 (the writer of node+0x34), the veneer
   0x8D8000 → 0xAE3020, and whether stream-cache mode applies.
5. **M6-031's "no logs, sends or DSP"** holds only for the direct bodies. H3 runs the music-engine Term, which is unread.

## M6-034 (Term recipients)

- **Confirmed:**
  - T1 (0x9AD064..0x9AD298), T3, T4, T5, T9, T13, T16, T19, T22;
  - H1;
  - A1–A4;
  - the receiver variants (0x99EAF0..0x99EBBC; vtables 0x103A9E0 and 0x103BF48);
  - the node body (0x9EAF90..0x9EB0E4);
  - the Term order (0x99DCEC..0x99E2E0).
- **Corrections:**
  - **T18** frees **seven** 0xC descriptors, not four (0xA10A50..0xA10A88).
  - **H2's argument** is the code address 0xA3D3D4, and 0x9A5D48 is UnregisterGlobalCallback(fn, mask 0x48).
  - **H3:** the registrar is 0x9A5AFC. The music-engine init 0x97D72C (called by Anki at 0x8D8206) registers
    0x97D834 with mask 0x40 (Term). At Term, that tail-calls 0x97D528 if [0x108D7D8+0x3C] is set.
- **Traps:**
  - **0x9A7B80** dereferences null when every bucket is empty (new; M1-034);
  - **T16's traps** fire only if another thread writes the list;
  - **the node trap** depends on the node callbacks.
- **Observable effects:**
  - thread effects: sem_post, join and destroy on 0x108DE70; the node's sem and join;
  - mutex destroys.

  No direct logs, files or messages.
