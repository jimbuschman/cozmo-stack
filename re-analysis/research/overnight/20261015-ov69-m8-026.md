Triangle helper 004E03B8..047E is fully read. For A=(ax,ay), B=(bx,by), C=(cx,cy),
P=(px,py), let F denote a separately rounded f32 operation:

```
x0 = F(cx-bx); y0 = F(ay-cy)
x1 = F(ax-cx); y1 = F(by-cy)
D = F(F(x1*y1) + F(x0*y0))
I = F(1.0f/D)
dy = F(py-cy); dx = F(px-cx)
a = F(I * F(F(y1*dx) + F(x0*dy)))
b = F(I * F(F(F(cy-ay)*dx) + F(x1*dy)))
c = F(F(1.0f-a)-b)
```

Accept only if each of a,b,c is ordered **strictly greater** than f32 bits
**B4000000** (-2^-23) and ordered **strictly less** than **3F800001** (1+2^-23).
Checks are a lower/upper, then b lower/upper, then c lower/upper; early return false.
`ble` after lower and `bpl` after upper reject unordered comparisons. NaN does not
count as inside. No denominator-zero guard or epsilon-adjusted denominator exists;
VFP division and subsequent comparisons determine degenerate outcomes. This preserves
the tolerance at edges without inventing a separate polygon winding rule.
