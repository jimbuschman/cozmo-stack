## OV31: M15-036, the Lab read

**Confirmed rows:**
- **The entry,** within the connection flow: SendConnectionResponse, then ReadLab, then ConnectRobotToNeedsManager
  (0x0052E3A2..0x0052E3B2; 0x0052FAD4..0x0052FAD8).
- **No robot:** return silently (0x006A5AB4..0x006A5AC2).
- **The clear:** clears the loaded vector +0x94, stride 0x18 (0x006A5AC4..0x006A5AF6).
- **The queue:** Read(0x196000). On failure: sErrorF "CozmoExperiments.ReadLabAssignmentsFromRobot.Failed" "Read
  failed", then `_errG` and break (0x006A5AF8..0x006A5B82).
- **The callback slot is +0x18** (0x010317D0 = 0x006A6487); +0x14 is the delete thunk.
- **The dispatch:** result ≥ 0 decodes. −1 logs Info "CozmoExperiments.RestoreLoadedActiveExperiments" "No lab
  assignments data on robot". Any other negative logs sErrorF "…ReadFailedFinish" "Read failed with %s", then `_errG`
  and break (0x006A5C3C..0x006A5D2A).
- **The decode:** a u8 count. If the count is missing, the vector is left untouched. The temp element is reused, and
  an element is appended only when Unpack returns nonzero, which is cumulative. Strings are a u8 length, then bytes
  (0x0078A970..0x0078A9CE, 0x0078D378..0x0078D3F8, 0x006C235C..0x006C2384, 0x006C39B0..0x006C3A18).
- **The restore loop:** to_string(id) once, then per element GetSecondsSinceEpoch and RestoreActiveExperiment; the
  result is ignored (0x006A5C46..0x006A5C80; 0x007EC042..0x007EC05E).
- **Eligibility:** returns 1 (no experiment), 2 (no variation), 3 (not running), 5 (AnkiLab+0 is 0) or 6
  (0x007ECE38..0x007ECEBE; 0x007EDBA2..0x007EDC0C; 0x007EE038..0x007EE0A6).
- **The running predicate:** S ≤ t ≤ E−1 and (t ≤ P−1 or t > R−1), unsigned 32-bit with wrap (0x007EDD16..0x007EDD5C).
- **FindAssignment and the signal:** a match replaces only the variation; otherwise the def is appended
  (0x007ECEF8..0x007ECF44; 0x007EBF42..0x007EC014; 0x007ED0B6..0x007ED0F4).
- **The listener:** UpdateLabAssignments copies into +0xA0, but not when the source is that same vector
  (0x004EB61E..0x004EB63E; 0x004EF212..0x004EF218; 0x006A60C4..0x006A60D0).
- **The clock** is a phone system library, so it's EQUIVALENT_IMPLEMENTATION.

**Two new records, both RECOVERABLE_GAP:**
- **The definitions:** AnkiLab::Load 0x007EBDE0..0x007EBF38 and the InitExperiments tail 0x006A56D0..0x006A5744. Without
  a load, every restore returns 1.
- **The writeback:**
  - the code: PossiblyWriteLabAssignmentsToRobot 0x006A5DE4..0x006A60C4, and WriteLabAssignmentsToRobot
    0x006A57F0..0x006A5A3C;
  - its callers: NeedsManager::InitAfterReadFromRobotAttempt 0x00694622, and SetGameBeingPaused 0x006990DA.

**Contradicted:**
- **M15-036's callback slot:** +0x14 should be +0x18. Its stack location "CozmoEngine.cs:1408 no-op" is stale; the
  code is now a NoSink at :1514.
- **M1-028:** 0x006A5AC4..0x006A5AF6 clears the loaded vector +0x94, not the active assignments.

**M1-034:** a dangling captured `this` at 0x006A648A, reachable only after a teardown race.
