## Build rows: M11-057

- **B1, the mode test:** bit 14 is read directly, as bit 6 of S+0xAD (0x006B30AE..0x006B30B4).
- **B2, the quantisation** (0x006B30B6..0x006B30F2):
  - r = e − 10·(e / 10), with a signed divide;
  - if r == 0, keep e and don't read maxE;
  - otherwise next = e + (10 − r), wrapping; ceiling = 10·trunc(maxE/10) (from S+0x88);
  - take the signed min of the two; on a tie, the ceiling is kept.
- **B3:** store {exposure, gain bits} to S+0x384/+0x388, then return 0. No log (0x006B30F4..0x006B3106).
- **B4, placement:** every non-failure exit of the proposal stage reaches B1. It runs only in CheckImageQuality, under
  mode 7.

## Build rows: the new CheckImageQuality record

- **The ROI head** (0x006B2D4C..0x006B2F58):
  1. The factor starts at 1.0f.
  2. **Whole image:** if MeterFromDetections (0x0105108A) is 0, or there are no rectangles: ComputeExposureAdjustment(image,
     factor).
  3. **Otherwise:** sum w·h as int32 (`mla`); overlaps are double-counted.
     - **If 2·area ≥ rows·cols** (signed): use the whole image.
     - **Otherwise:** build a weight mask filled with v = u32(f32(area)·255/f32(total)); fill each ROI with (~v)&0xFF.
       Then ComputeExposureAdjustment(image, mask, factor).
  4. The rectangles come from DetectMarkersWithCLAHE, DetectFaces and DetectPets in the same Update.
- **The failure exit:** a Warning, no channel, "Detection Quads=%zu" with the rectangle count, which skips B1.
- **The proposal stage** (0x006B2F5A..0x006B30AC):
  - **The thresholds:** 0x3F7FFF58 and 0x3F800054. Equality counts as the deadband.
  - **A NaN factor** takes the deadband path (`bpl`, then `ble`): exposure and gain unchanged, and B1 still applies.
  - **Quality** S+0x380 = 1 is set first.

  | Side | Order | Exposure | Gain |
  | --- | --- | --- | --- |
  | Decrease | exposure first | max(minE, s32(roundf(f·e))) | max(minGain, f·g) |
  | Increase | gain first; a NaN gain takes the exposure branch | min(maxE, s32(roundf(f·e))) | min(maxGain, f·g); a NaN product gives maxGain |

  `vcvt.s32` rounds toward zero, saturates, and turns NaN into 0.
- **Too bright:** factor below the lower threshold, e ≤ minE, and gain not above minGain + 1e-5 (NaN included).
  - ComputePercentile(LowPercentile);
  - if the result > TooBrightValue (unsigned), quality = 3.
- **Too dark:** factor above the upper threshold, gain ≥ maxGain − 1e-5 (or NaN), and e ≥ maxE.
  - ComputePercentile(HighPercentile);
  - if the result < TooDarkValue, quality = 2.
- **The quality enum:** Unchecked 0, Good 1, TooDark 2, TooBright 3.
- **The ImageQuality statics,** loaded by VisionSystem::Init (0x006B07D8..0x006B0E3E):

  | Static | Address | Default | Shipped value |
  | --- | --- | --- | --- |
  | TooBrightValue | 0x01051088 | 230 | |
  | TooDarkValue | 0x01051089 | 15 | **20** |
  | MeterFromDetections | 0x0105108A | 1 | |
  | LowPercentile | 0x0105108C | 0.1 | |
  | MidPercentile | 0x01051090 | 0.5 | |
  | HighPercentile | 0x01051094 | 0.9 | |

  - A missing key takes the Error, `_errG` and break-on-error path.
  - Init then calls SetAutoExposureParams(SubSample, MidValue, MidPercentile, MaxChangeFraction) (0x006B0A14).
- **Update's mode-7 block** (0x006B55E2..0x006B5690):
  - **On failure:** Error key 0x00C018BD with an empty format, then `_errG`, then return **without** push_back. **The whole
    frame's results are dropped,** for every mode.
  - **On success:** S+0x37C |= 0x80, then lock, push_back, unlock.
