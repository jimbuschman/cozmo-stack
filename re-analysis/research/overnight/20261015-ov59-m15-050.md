## Exact payload

LabAssignments::Size at0x0078A9D0..0x0078AA14 returns `1 + sum(2 + full_key_length + full_variation_length)` using native u32 accumulation. Empty vector size1. LabAssignments::Pack(buffer,size)0x0078A8F2..0x0078A916 creates non-owning SafeMessageBuffer, calls the buffer overload0x0078A926..0x0078A96E and returns its written count. The writer ignores that result.

The buffer overload stores **low8bits of count**, then still iterates **all entries**, stride0x18. Each LabAssignment::Pack0x0078A5F0..0x0078A610 calls string helper0x006C22DC for key, then variation. That helper truncates full string length tou8, writes that one-byte prefix, and writes exactly that many source bytes if prefixnonzero. It checks the prefix WriteBytes result; the caller ignores the helper's bool and still packs the next string. No terminators, alignment between fields, user string, magic, version, checksum or experiment percentages occur in this Lab payload.

For ordinary <=255-byte strings/count<=255 the payload is:

`[u8 count] [u8 keyBytes] [key raw bytes] [u8 variationBytes] [variation raw bytes] ...`

For one assignment `(key="a", user="ignored", variation="b")`, it is `01 01 61 01 62` (5bytes). Empty assignments are `00` (1byte), not an empty buffer. Native Size uses full string lengths while Pack truncates each tou8; strings>255 can therefore leave zero tail in the allocated vector. **The full allocation length is handed to NV.** Count>255 wraps only its prefix, while all entries are still packed. Neither method rejects these overlong cases before handoff. Do not replace these defined width operations with a convenient schema rejection. Size overflow/allocation failure is a separate malformed-input/terminating boundary, not exercised by the shipped three experiment definitions.
