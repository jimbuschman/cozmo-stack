## M15-029: the repair need's decay and part damage

- **D1:** Info on channel "NeedsSystem", key `NeedsState.ApplyDecay` (format 0x0069C594), with the index and the elapsed
  time as f64.
- **D2–D4:**
  - pick the first pair with level ≥ thr (BGE); no match means return with no store;
  - remaining = elapsed/60.0f (BLE also takes unordered);
  - rate = rate·mult (BLS);
  - walk the thresholds, keeping the last one.
- **D5/D6:**
  - clamp to MinimumNeedLevel (0.03) on MI;
  - store, then dirty = 1;
  - need 0 only: `PossiblyDamageParts(1)`.
- **T1–T8, PossiblyDamageParts:**
  - d = NumDamaged; return if d ≥ p (signed);
  - count the thresholds with `thr < level` broken on BMI, so **NaN counts every threshold**;
  - target = min(count, p); loop k = target − d times. Each pass:
    - PickPartToDamage, which runs RandInt(p−d) every pass;
    - damaged = 1;
    - `$data` = (d+1+i) + ":" + action;
    - sEvent `needs.part_damaged` with the part name.
- **The RNG:**
  - GetNextDbl = (f64 b·2³² + f64 a)·2⁻⁶⁴ from two words (a, then b), then L + (H−L)·v;
  - RandInt = trunc_s32(u·range);
  - mt19937 step and tempering;
  - the ctor sets L = 0, H = 1.
- **The thresholds:** "BrokenPartThreshold" 0..31, read until the first non-numeric value. The shipped values are 0.98,
  0.6 and 0.3.
- **Update's order:**
  1. the BLS deadline;
  2. ApplyDecayAllNeeds(robot ≠ 0), using config +0x164 when connected and +0x17C when not;
  3. SendNeedsStateToGame(1);
  4. a tail call to PossiblyWriteToDevice (Codex omitted it).
- **The endpoint chain.** u rounds to 1.0 for b = 0xFFFFFFFF and a ≥ 0xFFFFFC00. Then:
  1. RandInt returns range;
  2. Pick returns 3;
  3. key 3 is inserted (the map grows to 4);
  4. EnumToString(3) is null, so the sEvent value is null (0x0080D114);
  5. **WriteToDevice's PartIsDamaged loop then calls `Json::Value::operator[](nullptr)`** (0x00693E10..0x00693E18). That's a
     probable M1-034 crash point, unconfirmed inside JsonCpp.
- **Callers Codex omitted:** ApplyDecay from `HandleMessage<SetNeedsPauseStates>` (0x006989C8, an app input).

## New record: NeedsState::ApplyDelta

At 0x0069C8C8..0x0069CAC0.

- **The delta:** delta = center + f32(RandDbl(f64(2·var)) − f64(var)). The draw is unconditional.
- **The clamp:**
  - cand = old + delta;
  - cand ≤ min (BLS) → min;
  - otherwise cand ≥ MaximumNeedLevel (config+4) → max.
- **The return value:** if delta > 0, return (clamped ≥ the Full threshold).
- **Energy (need 1):** if new ≥ Full (BHI, which also skips on unordered) and old < Full (MI), set level = max.
- **Repair (need 0):**
  - **the cap:** d ≥ n → thr[n−1]; 0 < d < n → thr[d−1]; d ≤ 0 → max. If clamped > cap, level = cap − 1e-5;
  - **the floor:** thr[d] when d < n, otherwise min. If floor > the value, level = floor + 1e-5.
- **Then:** store, dirty = 1. If delta is negative and need == 0, `PossiblyDamageParts(action)`.
- **A missing map key** reads end-node+0x14 (0x0069C9AE..0x0069C9B4). That's undefined behaviour (M1-034).
- **Callers:** RegisterNeedsActionCompletedInternal (0x006968DE; its use of the return value is unread) and
  SetNeedsPauseStates (0x00698AC8, an app input).
