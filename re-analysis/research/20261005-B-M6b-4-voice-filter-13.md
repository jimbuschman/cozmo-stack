## 0. Answers in short
1. Frame count: T-V6 holds. LPF 0xA76A24 ldrh r3,[fp,#0xe] and 0xA76D54 ldrh r3,[r0,#0xe]; HPF 0xA777B0 and 0xA77ADC. Count = u16[S+0xE]; u16[S+0xC] only gives the plane stride *4 (0xA76A5C..0xA76A68, 0xA777E4..0xA777F0).
2. Channels: loops byte[S+4] channels, each with its own 16-byte history. The C# runs channel 0 only.
3. Bypass test: 0xA76750 is not a cutoff constant; it loads 0x3DCCCCCD (0.1f) from the pool at 0xA769E8. The comparison is the target percentage ([B+4], 0..100) with 0.1f, bls (lower or same); NaN is not bypassed.
4. Concrete Sound: LPF target 15.0 -> 13500.0 Hz, ENGAGED. HPF target 0 -> bypassed on the first apply and stays so.
5. The C# never writes the filter targets: FilterA.SetTargets, LowPass.SetTarget, HighPass.SetTarget have no caller outside WwiseVoiceFilter.cs. Native writes voice+0x340/0x350/0x510/0x520 from 0xA54F1C; the C# ports them as separate Ramp340/350/510/520 objects not connected to FilterA.LowPass/HighPass. In the C# engine path the filter stays at ctor state (target 0, bypassed).
6. Cutoff map: C# map bit-identical to native (200,002 evaluations at 48000 Hz).
7. Design arithmetic: the tan argument order and coefficient association differ from the C#.
