## New defects, not in the records before

- **M8-013 / M8-004, the ScoringChooser** (`Activities.cs:310-332`).
  - The C# adds `Random.NextDouble()`, in [0,1). The engine adds `Robot::GetRNG()->RandDbl(0.1)`, in [0,0.1), so the
    C# draw is ten times too large and comes from the wrong generator.
  - The engine computes in f32, with 0x3DCCCCCD and the 0.01f floor 0x3C23D70A, and keeps 0.01f on NaN
    (0x0060A3FC..0x0060A524). The C# computes in double, with decimal literals.
  - The tests pin the draw to 0.0, which hides the range error.
- **M7-014.** `Behaviors.cs:481-483` falls back to arbiter-wide `DisableReactions()` for a class with no lock table.
  The engine has no such fallback.
- **M7-003.** The record's text says InitInternal's return value is not specified. It is: 0 (`moveq r0,#0` at
  0x0060627A).
- **M7-021.** The log prints `Id` where the engine prints `EnumToString(+0x3C)` (0x005C0CB8). Robot::Update also reads
  +0x58 for the SDK status (0x00513F6A..0x00513F9C), which is unbuilt.
