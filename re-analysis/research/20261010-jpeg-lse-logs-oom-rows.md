## L. LSE marker (0xF8), color_transform

Registers in get_lse: r4 = cinfo, r6 = cinfo->src (`[cinfo+0x18]`: next_input_byte +0, bytes_in_buffer +4, fill_input_buffer +0xC), r8 = next byte pointer, r5 = bytes left.
Marker reader = `[cinfo+0x1D0]` (reset +0, read_markers +4, saw_SOI +0xC, saw_SOF +0x10). Every byte fetch is the INPUT_BYTE pattern: if bytes_in_buffer is 0, call fill_input_buffer; a FALSE return jumps to IMG 0x22424 (`movs r0,#0` / pop = suspension, FALSE).
Error codes are indices into the libjpeg message table, read from IMG `.data.rel.ro.local` at 0x171990 + 4*code (entry 0x46 at 0x171AA8 = "Unsupported marker type 0x%02x").
