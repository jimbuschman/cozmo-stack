## 1. Overhead frame → ordered map operations

Frame layout used here: timestamp+0, ground-valid flag+4, quad XY pairs at+8/+0x10/+0x18/+0x20, chain vector+0x28/+0x2C. Each chain is16 bytes, point vector begin/end at+0/+4 and kind byte+0xC. **Admission (P/PC33–34).** First erase debug segments. Unknown current origin, absent map or null map returns0. Request history at **frame timestamp**, interpolate=true. Result0x06000000 returns quietly; other nonzero result or null returned state logs “Pose not found for timestamp %u (hist: %u to %u). Edges ignored for this timestamp.” and returns.
