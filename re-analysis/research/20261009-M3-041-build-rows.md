## Exact payload-to-text contract (after formatter recovery/check)

These are expressions naming source-selected insertions, not implementations of numeric formatting:

```text
processed path: scope2(imu_logs) + /imuLog_ + unsigned_decimal(counter) + .dat
header:        aX aY aZ gX gY gZ\n
for i=0..7:    float_insert(AX[i]) SP float_insert(AY[i]) SP float_insert(AZ[i]) SP
               float_insert(GX[i]) SP float_insert(GY[i]) SP float_insert(GZ[i]) LF
raw path:      scope2(imu_logs) + /imuRawLog_ + unsigned_decimal(++counter) + .dat
               repeat ++counter while FileExists(candidate)
header:        timestamp aX aY aZ gX gY gZ\n
one row:       decimal(byte timestamp) SP decimal(short AX) SP decimal(short AY) SP
               decimal(short AZ) SP decimal(short GX) SP decimal(short GY) SP decimal(short GZ) LF
```

No spaces/newlines enter filenames. No comma is emitted. Payload values are unmodified; the float insertion's widening and packaged formatting are additional source obligations, not an IMU unit conversion. Metadata order/chunk fields are not written into either file. The timestamp is one received byte, not engine time.
