## Answer

The native constructor arguments are **head(target angle, angular tolerance, angular variability)** and **lift(target height, height tolerance, height variability)**. Their final zero argument is **not duration or acceleration**. Duration is a separate zero-initialized action field. Head's engine-internal defaults are speed15rad/s, acceleration20rad/s², duration0; lift's are speed10rad/s, acceleration20rad/s², duration0. The pyramid callback does not overwrite these constructor defaults.

The lift constructor receives target **0mm**; the existing native lift Init clamps that defined out-of-range target to **32mm** with its warning. Therefore its possible robot command is height32, speed10, accel20, duration0, not raw height0. Existing action Init/ack/completion ownership remains M4-016, with height/clamp M4-002.
