# B-M6b-4 batch 4a MISSING items: extraction

Read-only pass over `resources/lib/armeabi-v7a/libcozmoEngine.so` (ARM mode, Wwise runtime `0x0095E540..0x00AE2E40`; Thumb code outside it). Every address was disassembled from the `.so` with capstone (a constant-tracking wrapper resolves `ldr rX,[pc,#..]`, `add rX,pc,rX` and GOT loads; a GOT slot at `base+off` holds a pointer to the named global, base `0x104028C`). Bank facts were parsed from `re-analysis/obb/sound_meta/*.bnk` with the layouts the engine code itself reads (stated where used). The C# was not consulted. Existing-record columns quote inventory `M6-wwise-bank.md` row ids, manifest ids or report/check lines as found in the files.

Notation: `pbi` = the PlayingInstance; `ctx` = `pbi+0xC` (the context sub-object built by `0x9BC90C`); `voice` = the 0x540-byte voice. `[voice+8] = pbi+0xC` (proof: `0xA55940..0xA55948`: `ldr r3,[r5,#0xc]` (source+0xC = pbi), `add r3,r3,#0xc`, `str r3,[r4,#8]`).

## Headline results

1. `0xA54A30` returns only 1 or 2. 2 comes from: `0xA5321C`/`0xA47038` non-1 (pool allocation failure, only for a source with more than 8 channels), the first or second `0xA764D4` non-1 (pool allocation failure), an FX-slot-object allocation failure. `0xA5676C` always returns 1. A failure of one insert-FX slot does not fail the voice. For shipped Cozmo data the voice init fails only on pool exhaustion.
2. Insert-FX slots matter for shipped data. 1872 of 2231 Cozmo.bnk Sounds inherit the FX list of ActorMixer 62050212 (one FX: FxShareSet `0x89DDC03B`, plugin key `0x006C0003` = Wwise Compressor). The plugin registry (`0x108D9DC`) is filled only from a static list (two entries: Anki Hijack `0x000112C3`, Anki Wave Portal `0x006412C2`) and a DLL loader (`0xA57238`) whose libraries are not in the APK. No registration of `0x006C0003` was found, so `0x9CC2AC` returns 2 and the slot is skipped (no FX object; `voice+0x370..0x37C` stay 0). Not absolute: see 1.18.
3. Init.bnk buses, decoded with the layout of `0x9C6420`/`0x9C0D08`: no bus has a mixer plugin, `[bus+0x46]` bit7 or `[bus+0x40]&0xE0000`; Cozmo_Robot and Robot_Bus_1..4 carry config `0x4101`, all others 0.
4. `[gameobj+0x22]` (listener mask) is 1 for every Anki-registered object (`0x8D8CA0 movs r2,#1`, `0x8D8CA4 blx 0x9A3100`); `[gameobj+0x78]` is always -1.
5. The citation check's row 5.13 correction is wrong: `0x9D3CC0` works on `pbi+0x1D8`, `pbi+0x164`, `pbi+0x1BC`, `pbi+0x1F8` (the check read `[voice+8]` as `pbi`; it is `pbi+0xC`).
6. `0x9D3864` is the tail of `0x9D3C98` (`0x9D3CB8 b 0x9D3864`). Per frame `0x9D3C98` (0x9AFA7C) runs before `0xA57FF8` (0x9AFA90) and before the message drain `0xA38420` (0x9AFA94); `0x9D3CC0` runs inside the voice pass (`0xA44978`) inside `0xA57FF8`.
