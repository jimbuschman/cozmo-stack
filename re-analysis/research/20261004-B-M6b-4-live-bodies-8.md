## Findings first

1. **The pitch node is fully read** (0xA53134, 0xA52D4C, 0xA52EBC, 0xA52F9C, 0xA53030..0xA531A0, 0xA5268C, 0xA52800): rows P1-01..P1-15. A Python model of the whole node (including start-offset skip, last-buffer, marker carry, first-buffer fill, release) agrees with the real engine code run under emulation on 1500 random scenarios. New behaviours no record had: the output buffer is allocated at every pull and freed after the mix; the marker carry stores offset 0 and a count equal to the last call's additions; the first buffer starts with n silent frames from the play delay; the 0x11 path copies S only when the node holds no frames.
2. **The resampler is fully read for every shipped configuration** (float and int16, mono and stereo, modes 0/1/2; 3+ channel kernels unread, not shipped): rows P1-12..P1-16, bit-exact models verified on 400..600 random cases per kernel family. Facts that change a port: SetPitch takes **float** cents; the int16 mode-1 kernels switch to a NEON float formula for part of every call; int16 stereo mode 0 has a +1 LSB quirk on the right channel; kernels carry an output offset, an input offset, a history register and a limit across calls; Execute switches mode 2 to mode 1 when the ramp counter reaches 0x400.
3. **Hijack and the 744/22320 delivery verified with the real Thumb code under emulation** (rows P1-18, B-06, B-07): step 140938, 744-frame chunks, partial flush on an empty input, and the bus buffer's valid count is 0 after the Hijack.
4. **Voice insert FX on shipped data** (V2-02..V2-04): 1872 Cozmo Sounds carry a Compressor in slot 0; Harmonizer on 173 (139 bypassed); a four-slot chain on 25; all five plug-ins are in-place, so only the in-place wrapper (fully read) is used. The plug-in DSP bodies are not read (entry points listed).
5. **Mix** (V2-05..V2-07): 0xA4FBEC and the matrix mixer verified by emulation; the frame count mixed is the bus frame count, and the ramped gain is generated per NEON lane with accumulation (not start + k*delta).
6. **Bus chain** (B-01..B-05): order, the state machine with the empty-buffer tail frame, lazy FX creation with format {mix rate, bus config, float}.
7. **SourceNotReady is a no-op on the app path** (P1-19).

The voice-stage kernel is chosen by the source's sample format (`F[8] & 0x3F` via 0xA47038 / 0xA47528): shipped Vorbis (1750 + 11 + 8 Cozmo DIDX media, 24 SFX, 4 UI) is **float**, only ADPCM (227 Cozmo DIDX entries) is int16. The "bypass x1/32768" is the int16 mono mode-0 kernel only; float bypass is a plain copy (0xA479F4).
* **Inventory row 3.5 / M6-004 "`(double)(ratio*powf(2,cents/1200)*65536)+0.5`":** the product is computed in float32 before the widening (two vmul.f32); with the 0xA47384 flow (+0x57, same-cents, ramp-fold) in P1-12 it reads as a state machine, not as one formula.
