### F01 · Managing a live spoken turn

**Reachy Mini implements this better. High confidence in the software path.** The app streams input samples while output is active. Server speech start interrupts playback, and local detection can duck output ahead of confirmation. It tracks the first audio delta separately from response completion. Cozmo's in-repo command entry point takes English text, waits on the native action and can cancel against its original owner. Its MCP catalogue contains no equivalent microphone-to-turn service. An external client could supply one. A practical first experiment combines host push-to-talk with Cozmo's own spoken reply. No acoustic latency advantage in milliseconds can be inferred between these robots. ### F12 · Connection failure, diagnostics and recovery

**Both implement comparable capabilities for diagnostics. Neither implementation adequately addresses end-to-end reconciliation after a lost session. Medium confidence.** The Reachy SDK reconnects with backoff, the app retries abrupt closures, and the motor backend counts errors and escalates after a no-response interval.
