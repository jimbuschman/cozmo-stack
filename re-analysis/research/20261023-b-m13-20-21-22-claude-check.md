   (0x0067E330..0x0067E338), a byte written only by HandleCliffEvent (0x005356C6..0x005356D4: `ldrb r1,[r6]`,

   (`Sensors.cs:296`). The stack already has the event byte: `Sensors.CliffDetectedByEvent` (`Sensors.cs:562`).
2. **Saved pose kept per map instead of per MapComponent.** The engine's saved pose is MapComponent+0x2C (0x0067E252,

   `_lastRobotPose` per MemoryMap and releases it on Clear, zombie removal, UpdateMapOrigins and Dispose. After a
   relocalization to a kept older origin the stack compares against a stale pose, does two inserts and an extra
   ProcessClearQuad the engine skips.

## B-M13-22 blocking

3. **The charger Pose setter overwrites the caller's old pose.** The new setter assigns in place
   (`_pose.AssignInputValue(value)`), and the getter returns `_pose` itself. WritePoseHelper captures
   `var oldPose = obj.Pose`, then SetPose, then BroadcastObjectPoseChanged(obj, oldPose, ...): for a charger oldPose now
   holds the new pose. The engine copies first: GetPose 0x005060CA, PoseBase copy ctor into sp+4 at 0x005060D2, SetPose
   (vtbl +0x28) at 0x005060F0, the copy passed at 0x005060F4..0x005060FA. Same pattern in AddObjectRelativeObservation,
   ApplyRelativeObservation and DriveActions' PreActionObjectPose. Feeds `_poseChanges` and Maps.UpdateObjectPose.
