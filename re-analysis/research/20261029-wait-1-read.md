## Observable result
- W sends nothing and starts no action, and it never ends by itself.
- It is runnable off treads and while carrying, but not while robot+0x34A.
- Nothing is delivered to the C# API beyond the base lifecycle.

## C# stack before the build (facts)
`WaitBehavior` is in `ExplorerBehaviors.cs:536-541`. It already matches on:
- never ending (KeepsRunningWithoutAction true);
- the base IsRunnableInternal, Resume and Stop.

It differs in these ways:
1. The +0x24 gate is not overridden, so the base returns true and the stack's W is runnable with robot+0x34A.
2. The +0x20/+0x28 base defaults are true but report a misleading MISSING.
3. OnStart logs an invented "waiting".
4. The no-vision build (`FreeplayStack.cs:133`) has no `Wait` ID.
5. `executableBehaviorType` is not read (no G2E channel).
6. ActivityFeeding is not built.
