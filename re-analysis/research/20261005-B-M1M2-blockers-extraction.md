## 1. NeedsState::ApplyDecay

Entry ABI: `r0 = NeedsState*`, `r1 = DecayConfig const*`, `r2 = int need`, `r3 = float elapsedSeconds` by bit transfer, caller stack argument = reference to three float multipliers. `s16` initially receives elapsed, but is reused for the threshold/output. Levels live in `map<NeedId,float>` at state+0x34; the node value is a float at node+0x14. This is not a double-valued state operation. `DecayConfig` holds three rate vectors; each vector header is 12 bytes and each `(threshold, perMinute)` entry is 8 bytes. `InitDecayRates` reads Threshold and DecayPerMinute and calls the descending-threshold sort at `0x0068EFC6`; ApplyDecay itself does not sort or choose an alternative rate table.
