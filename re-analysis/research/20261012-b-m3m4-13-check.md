## Blocking

1. **`$session_id` form** (CozmoEngine.cs:1485 at 88da56ad). The native argument at 0x0052E38A comes from
   `Anki::Util::GetUUIDString` (0x00831578):
   - it builds `RandomGenerator(0)`: seed 0 means an entropy seed, as the stack's `EngineRandom` already does;
   - it makes two `(u64)(GetNextDbl() * 2^64)` values (d8 = 0x43F0000000000000 at 0x00831600, `__aeabi_d2ulz`), stored
     at sp+0 and sp+8;
   - `StringFromUUIDBytes` (0x0083B814) formats those 16 bytes in memory order with
     `%02hhX%02hhX%02hhX%02hhX-%02hhX%02hhX-%02hhX%02hhX-%02hhX%02hhX-%02hhX%02hhX%02hhX%02hhX%02hhX%02hhX`
     (0xC28F8E), then uppercases through `_toupper_tab_` (0x0083B8A6..0x0083B8BA).

   The result is uppercase, with no version or variant bits. The stack sent .NET `Guid.ToString()`, which is lowercase
   v4.
2. **The device-ID loader edge cases** (DasControl.cs:121-131; M3-058, DAS.java:159-242):
   - **A zero-byte file** (`readLine()` returns null): Java generates a new ID and overwrites the file. The stack used
     "".
   - **A failed create or write:** Java swallows FileNotFoundException/SecurityException and still returns the new ID.
     The stack lets UnauthorizedAccessException/DirectoryNotFoundException escape, so engine startup throws.
