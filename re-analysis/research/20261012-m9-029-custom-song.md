## Selection and resulting animation

For each stored `(type,duration)` pair, the native table lookup produces a generic event ID, then a RobotAudioKeyFrame contains **one** AudioRef with layout `{uint32 event; float 1.0f; float 1.0f; byte 0}` at the constructor input. Native table bytes establish IDs; shipped generated enum names cross-reference them.
