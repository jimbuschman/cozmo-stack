# B-M6b-4 live-bodies extraction, pass 2 (extractor report)

> **Status (manager, 2026-10-03): UNVERIFIED.** The cozmo-extractor may not write files and its transcript was not kept, so this is the manager's transcription of its hand-back, condensed but with every citation and every numbered row. It is an extractor report: every row is checked by a verifier before any inventory correction adopts it. It rests on emulation under Unicorn for two oracles (`0x9B49A4` then `0xA1EC54`; `0x9E2BD0`/`0x9E2AE4` on an all-zero object) and on census scripts over `re-analysis/obb/sound_meta/English(US)/Cozmo.bnk` and `AudioAssets.zip`. It did not redo the rows of `20261003-B-M6b-4-live-bodies.md`.

## Headline claims (all unverified)

1. The media table is written by the bank load: Anki `LoadSoundbank(name)` posts command 0, which runs the loader in mode 0; the writer is `0x9B49A4`, called at `0x9B7A34`. `0xA1EC54` returns `(DATA buffer + DIDX offset, DIDX size)`.
2. The DIDX entry of each of the 2131 streamed Cozmo sounds is only a prefetch prefix of a longer `.wem` in `AudioAssets.zip` (1826 Vorbis and 305 ADPCM are proper prefixes; 28 ADPCM equal their full `.wem`). This contradicts inventory 4.5.
3. The vtable labels for the Vorbis sources are reversed. `srcType 1` (stream byte 1 or 2) builds the 0xFC-byte class, vtable `0x103E138`; `srcType 3` (stream byte 0) builds the 0xD0-byte class, vtable `0x103E0B8`. `vt+0x28` is `0xAB22D4` for the first and `0xAB0B20` for the second; `0xAB0448` and `0xAB1550` are `vt+0x30`.
4. Several seams are unreachable for every shipped node: `0x9F1F80` returns 0 with `*out = 0`; `0x9EEDA4` returns code 0, index 0; the plug-in halfword is never 8. So `0xA37A80`, the code-3 branch (node `vt+0x10`/`vt+0x120`), `0xA37BA8` and the `0xA37C90` external-source branch never fire on shipped data.
5. On the shipped path `0x9BEB30` calls `0x9FB9B8` then `0x9FFAD4` (CalcEffectiveParams); it never calls `0x9BE898`, `0x9BC66C` or `0xA11F98`; it returns 1.
6. The engine default frame count is 1024 (`0x99DC88/0x99DC90`); Anki's init code does not change it; `0xA57724` rounds it against the platform property. The rate is `min(AudioTrack native rate, 48000)`.
7. V28 is a no-op when its three lists are empty (emulation); whether they stay empty on shipped data is unproven.
