# B-M6b-4 live bodies 4: bus walk, RTPC evaluation, source classes, bank chunks, Sound Play gate

> **Status (manager, 2026-10-03): UNVERIFIED.** Saved verbatim from the cozmo-extractor's scratch file. A verifier checks the rows before any inventory correction adopts them.


Read-only extraction. Every address is a VA in `resources/lib/armeabi-v7a/libcozmoEngine.so`, checked by disassembling the `.so` (ARM mode unless marked Thumb). "vt+N" is `[vptr+N]` (C28 convention). Scratch tools (scratchpad only): `d.py` (disassembler with GOT/literal resolution), `xref.py`, `memrefs.py`, `ptrs.py`, `gotuse.py`, `bnk.py` (my own HIRC parser over `re-analysis/obb/sound_meta`). "Shipped data" = the six banks there (every HIRC object consumed exactly by my parser). Floats are given as the value of the raw bits.

Status words: EXACT_SOURCE = body fully read; RECOVERABLE_GAP = named bodies still to read; UNKNOWN = not settled (what I tried is stated).

## 0. Headline results

1. **The bus walk is small and fully read** (B1..B13). On shipped data: 2069 Cozmo.bnk Sounds (+12 Dev_Debug) have first output bus `Cozmo_Robot` (1723505802). `0x9C54E8` returns 1 for it (channel word `0x4101` -> `[bus+0x68]` byte 1), so `CalcEffectiveParams` takes the `s16 = 0.0f` branch (`0x9FFC14..0x9FFC1C`) and `0x9C39DC` is not called from that site on the robot path.
2. **The cached path `0x9FFEE4..0xA00000` is reachable on the Play path.** `0x9BEB30` passes `r1 = params+0x8C` (non-null) to CalcEffectiveParams; the Play-action builder zeroes `params+0x114/+0x11C`. The compare `[r7+0x90] == bus` is true exactly when the first bus is null: 143 bus-less Cozmo.bnk Sounds (+1 SFX.bnk) take the cached copy of an all-zero block (B12). Sounds with a bus take the uncached path.
3. **`[ctx+0xD0] != 0` branches, `0x9BE898` as a producer, `0x9FB17C`, `0x9FD8C0/0x9FD8D0`, `0x9FF0D8` are not reached by any shipped node**: `[ctx+0xD0]` and `[ctx+0xA0]` become non-zero only through the 3D-positioning object, which only positioning-byte bit 3 creates (B14..B17, R10). One native oddity is UNKNOWN (R11: two callers of `0x9BE898` read an out-pointer it never writes when `[ctx+0xD0] == 0`).
4. **The modulator path IS reached on shipped data** (R6..R9): 13 modulator-bound RTPCs on Switch containers and one on ActorMixer 1000217986 (`cozmo_scrn_glitch`, 34 Sounds, first bus `Cozmo_Robot`). `0x9E8224` is read in full; `0x9E62AC` control flow is read; its callees `0x9DCE44`, `0x9E61B4` and the list producer `0xA6E848` are not (RECOVERABLE_GAP).
5. **`0xA17280`'s not-in-store branch is mis-described** in the inventory (7.3) and the C# (`WwiseRtpcStore.cs:14-20,379-382`): for `type != 1` and param not in {0,7} the code falls through to the same `0x9E6748` call as `type == 1` (R3).
6. **HIRC types 10..13 (music) are created only through a hook** `[0x108D868+0x100]` which `0x97D72C` (music-engine init) sets to `0x984930`; Anki calls it at Thumb `0x8D8206`. With a null hook the loader skips them silently (K9, K10).
