## Corrections

- **M12-023:** PATH_INTERRUPTED sets status 4 **only if id == +0x42** (after the helper). PATH_COMPLETED sets 4 whatever the
  id.
- **M12-032's evidence:** the UpdateCurrentPathSegment row omits the gate (+0x42 ≠ 0 and +0x44 == +0x42), which also
  controls the +0x40 store. 0x0064937C and 0x00649390 are dead code.
- **The stack's PathSender** sends all segments after a ClearPath. The engine sends at most Dole(6), then doles more on
  RobotState (P19).
