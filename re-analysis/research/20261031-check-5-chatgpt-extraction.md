### Paths not checked to complete equivalence

- Full object allocation/destruction and every malformed-JSON exception landing pad (factory, reload, chooser constructors).
- All `IBehavior` native subclass score overrides beyond the four named, and all downstream writers of per-class score fields. In particular, the amount of behavior-specific score change for each live runtime state is not determined by merely finding an override.
- An independently proven binary-to-host `BehaviorID` equality mapping for every invalid/out-of-range ID, and complete `Selection` game-to-engine delivery in the standalone app boundary.
- Actual bound `IBehavior` set in every shipped configuration and whether host readiness can make a named strict-priority candidate unavailable.
- Proven identity between native Robot RNG/seed and host EngineRandom/System.Random fallback across all call sites; exact tick timestamp synchronization.
- Complete effects of `Selection` analyzer enable requests on downstream map/vision execution, and virtual caller of OnSelected/OnDeselected for every activity type.
- The display/log text for every error and config failure, and all numerical NaN/Inf boundary cases.
