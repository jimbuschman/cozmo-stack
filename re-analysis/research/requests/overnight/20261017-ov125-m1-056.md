- **Date:** 2026-10-17
- **Requested by:** manager
- **Kind:** independent extraction

## Why this is needed

M1+M2 is the acceptance target. The OV124 check (`research/overnight/20261017-ov124-check.md`) found that no record owned
CozmoEngine::Update's states 1 and 2, and that the state-2 tick ends with an EngineLoadingDataStatus send. It also left
open whether the game ever receives the Init-time broadcast (0x0052E76E): Init runs before any UI device is connected.

Current record: M1-056, RECOVERABLE_GAP. Re-read the current manifest before answering.

## Questions

1. **State 1 → 2.** From Update's switch (0x004ED5C4 ldrb engine+0x62, tbb 0x004ED5CC): read HasDesiredNumUiDevices
   (its count source and the desired number), SendSupportInfo (0x004ED5E2: every message, field and value it sends,
   and its order) and SetEngineState (0x004ED5EA and the call at 0x004ED60E: what it stores and every message or log
   it emits, with payloads). State whether anything else runs in state 1.
2. **State 2 per tick.** The loading case 0x004ED5F0..0x004ED618 and 0x004ED7C0: the EngineLoadingDataStatus payload
   (fields, widths, the progress value's source and type), the order relative to the M1-055 broadcast and
   SetEngineState(3), and what happens on a tick where loading is not done. Note 0x004ED7C0 dereferences context+4
   without a null check (0x004ED7D2): say whether context+4 can be null on the production path.
3. **Delivery with no UI device.** UiMessageHandler::Broadcast(MessageEngineToGame&&) at 0x006625B0 calls virtual
   [vtbl+0x48] with r2 = -1 (0x006625CA..0x006625CE), then a local event dispatch (0x006625FA). Resolve the concrete
   [vtbl+0x48] target and say what it does when no UI device is connected (drop, queue, or other), with citations.
   From that, state whether the game receives the Init-time AnimationAvailable/EndOfMessage messages.
4. **Progress writes.** Where the loader's progress float (loader+0x270) is written during loading, beyond the final
   1.0 at 0x0051F480..0x0051F48C, so the stack knows which values EngineLoadingDataStatus can carry.
