becomes ready. The stack has no UI device, so it must know how the state 1 → 2 gate is met, and what the state change
does that the stack must reproduce. Current record: M1-056, RECOVERABLE_GAP. Re-read the current manifest first.

Under the 2026-10-17 standard, answer only what touches robot traffic, robot behaviour, C# API delivery or readiness,
or downstream engine state. Say "no such effect" with citations where that is the answer.
