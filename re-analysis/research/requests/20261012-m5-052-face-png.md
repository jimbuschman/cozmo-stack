## Task

The engine loads each face frame with `cv::imread(path, IMREAD_GRAYSCALE)`, from
`resources/lib/armeabi-v7a/libopencv_imgcodecs.so` and its PNG decoder. Then it applies `Threshold(0x80)` (F17).
The shipped set has 552 PNGs, all 128×64: 510 are 8-bit and 42 are 1-bit.

1. In the shipped `libopencv_imgcodecs.so`, follow the PNG path that `imread` takes with flag 0 (grayscale).
   - Which libpng transforms are set: expand, strip_16, gray_1_2_4_to_8, rgb_to_gray and any others?
   - Is libpng linked statically, and which version?
   - Cite addresses.
2. For a **1-bit** PNG: what 8-bit values do pixels 0 and 1 become (0/255, or 0/1)? Does a palette or tRNS chunk
   change that?
3. For an **8-bit** grayscale PNG: is the decode the identity? Are any gamma, sBIT or colour-type conversions applied?
   If any shipped file is RGB or RGBA, give the rgb_to_gray coefficients and the rounding, from the binary.
4. Using the tools in `re-analysis/tools/emu/` if they help, decode **three** shipped 1-bit files and **three** 8-bit
   files through the shipped decoder, if you can run it. Otherwise decode them with libpng locally, as a cross-check
   labelled authority 6.
   - For each, give the sha256 of the 128×64 output buffer.
   - Give the count of pixels at or above 0x80 (the threshold input).
