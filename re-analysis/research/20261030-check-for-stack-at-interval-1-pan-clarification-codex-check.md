# PanAndTilt return clarification

Correction to the reader report R1's phrase “absolute head0” and this reviewer's earlier wording: the native tuple is `(saved root yaw, 0, true, false)` and the head zero is **relative**, not absolute. Caller 0x005D78A2–78B0 stores stack booleans 1,0; constructor 0x0054969A–6AA transfers them respectively to +0x124 and +0x125. Init 0x00549C6A–72 passes +0x124 to the pan child; 0x00549CD0–CEF tests +0x125, and on zero loads robot+0x2FC and calls Radians `operator+` with the supplied head angle. Thus zero preserves the current head target, subject to the shared action path. The frozen draft's `PanIsAbsolute=true, HeadIsAbsolute=false` matches the tuple. This is a prose clarification, not a separate code-review correction batch or an inventory status change. `known.py` was consulted before the native trace; no .NET or hardware.
