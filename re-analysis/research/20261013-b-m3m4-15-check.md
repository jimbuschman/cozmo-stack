## Blocking

**A BOM in the device-ID file** (DasControl.cs:126):
- **The stack** reads with `new StreamReader(path, Encoding.UTF8)`, which detects and strips a UTF-8 BOM, and decodes a
  file with a UTF-16 or UTF-32 BOM in that encoding.
- **Java** (DAS.smali getDeviceID: `FileReader(File)`, then `BufferedReader.readLine`) uses Android's default UTF-8
  decoder. It keeps U+FEFF as the first character, and decodes any other bytes as UTF-8, with replacement characters.
- So the ID, and its MD5 for `$player_id`, differ for such a file. Only a file written outside the stack can reach
  this.
- **Fix:** read the first line as UTF-8 with no BOM detection.
