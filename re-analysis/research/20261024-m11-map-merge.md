## Math and walk, using Q5 and later corrections

F means one f32 operation/rounding, D one f64. No FMA/reassociation. The two transform uses are intentionally different:

1. **Planar reinsertion transform.** Pose2d(Pose3d)0x00846594..0x00846610 takes local XY and GetAngleAroundZaxis, with no parent copied. PR R14: quaternion wxyz remain f64 while computing m01=D(D(x*y)−D(z*w)) doubled by addition to itself, m11=D(1−D(D(x*x)+D(z*z)) doubled), m10 from xy+zw doubled, m00 from y²+z² likewise; each final matrix term narrows f32. Compute A=F(F(m01*m01)+F(m11*m11)), B=F(F(m10*m10)+F(m00*m00)). If **ordered B>A**, atan2f(m10,m00); otherwise tie/unordered atan2f(−m01,m11), negation as sign-bit flip. Returned Radians(float) sets rescale flag; use P/PR R2 exactly: interval(−πf,πf], −πf becomes +πf; strict abs(v)<10 small repeated±2π additions, else large ceilf/conversion branch, no final recheck. NaN remains NaN; ARM conversion rounds toward zero/saturates/NaN→0 per PR. Do not replace this with unwrapped atan2 of one arbitrary matrix pair.
2. **Budget transform.** Q5b/section5: rotate source root XYZ centre by the full supplied 3D quaternion using P R7/R8 (first narrow quaternion components f32, then its ordered f32 point products/adds). Add supplied translation componentwise f32, subtract destination root XYZ centre componentwise f32. Sum squares x then y then z with separate f32 multiplies/adds. vsqrt.f32; only NaN result falls back sqrtf. Divide by bits32(0x44A00000)=1280f, ceilf, vcvt.s32.f32. Compute **once**, before the leaf loop. Coincident centres give0, not1; vertical displacement can affect budget even though planar reinsertion discards Z/roll/pitch.
