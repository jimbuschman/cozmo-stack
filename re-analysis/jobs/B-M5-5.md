## 1. Blocking

1. **A string colour is the NamedColors word, unconverted** (`JsonClipLoader.cs:257` → `AnimationClip.cs:236`
   `AsRawComponents` → `BackpackColor.GetColorOptional`).
   - **Native:**
     - `isString` (0x0084026E);
     - then `asString`;
     - then `NamedColors::GetByString` (0x00840282);
     - then `ldr r0,[r0]; str r0,[r4]` stores the 32-bit word as is (0x00840286..0x00840288);
     - and it returns 1 (0x00840298).
     - **No** component conversion and **no** warning.
   - **The stack** runs the named colour through the float-component converter. For `"BLACK"` (0x000000FF) it emits
     `ColorRGBA.GetU8.OutOfRangeValue` for alpha and stores alpha 0x01.
   - **Fix:** store the table word directly on the string path. The OutOfRange warnings (0x008404A8) belong only to the
     array path.
   - **Test:** `"BLACK"` and one other name from the table give the table word bit for bit and no warning. An unknown
     name gives whatever GetByString returns for an unknown name. Read that at 0x004CDE44 and cite it; don't assume it.
