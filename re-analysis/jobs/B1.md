**Agent:** opencode (DeepSeek), window 2, in its own build clone. **Type:** build. **Needs:** X5 DONE and its report turned into an approved M6 inventory correction by the integrator. Until then, B1 waits: its status reads `WAITING X5`.

## Scope

- **The IMDCT:** build the exact NEON IMDCT kernel from the approved correction, and vendor the table.
- **The wiring:** wire the M6 runtime, built in pieces since 2026-09-26 and still unwired, into the live audio path. The layer is done only when the robot's audio comes from the engine's path.

## How to do it

1. Read `re-analysis/jobs/README.md`, `AGENTS.md` and `.opencode/agent/cozmo-manager.md`. Work as the manager for this one job only: `@cozmo-implementer` builds, `@cozmo-verifier` verifies, and a MISSING goes to `@cozmo-extractor`.
2. Claim the job in `re-analysis/jobs/status/B1.md`.
3. One batch: implement all of it, verify the whole diff, fix, and re-verify the fixed hunks.
4. The gates:
   - `fidelity.py --check` passes;
   - the verifier gives PASS;
   - the full suite passes, with `AssetPresenceTests` green.
5. Commit only B1's files, `git pull --rebase`, and push. The push gate runs the suite again.
6. Set the status to `DONE`, with the commit hashes and what an operator should listen for on the robot.

**Write scope:**
- `cozmo-stack/src/Cozmo.Robot/Animation/**`, and whatever else the wiring strictly needs (list it in the report);
