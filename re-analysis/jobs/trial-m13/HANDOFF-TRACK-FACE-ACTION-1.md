## Source and scope

The default profile uses 2° and no small-angle clamp.
- ActionList drives the runner on the engine tick (0x0065B3D2, 0x005140BC, 0x00540592). Shared Init saves live-idle parameter 0x16 and sets it to 1 (0x00564DAC–0x00564DC6). Derived Init checks the external interface, subscribes to local 0x47, writes the separate tracking face field and clears the observation stamp (0x00565C24–0x00565CFC). - Face geometry uses the historical carrier camera under VisionSystemOrigin (0x006AF362–0x006AF36A, 0x00513AB0–0x00513B16, 0x006B26E0–0x006B26E8). The position is formed from the existing camera-frame ray (0x0087DE24–0x0087E068), parented to that camera and flattened through the tree in engine order (0x006B37B4–0x006B37EC), then owned by the observation-time origin (0x004F42B4–0x004F42F2). A no-eye-parts update retains the previous native translation under the new observation origin (0x004F477E–0x004F47BE). The tracker reads the native position only. The face's existing public pose remains separate.
- The runner requires the selected face in the current world root (0x004F597E–0x004F59C2), commits only an unsigned newer timestamp before pose conversion, and computes pan from local atan2 plus checked MAIN yaw and tilt from atan((z−49)/sqrt(x²+y²)) (0x00565DBC–0x00565F76). Missing, stale and degenerate samples leave the default zero-timeout action running (0x00565428–0x00565454). - Fresh commands use the existing motor ID and reliable packet owner. Head sends first with |delta|/0.15 and acceleration 10000 (0x005650E2–0x00565104). If pan warrants a body turn, off-treads then returns 0x0300000A, even if a head command was sent (0x005653A6–0x00565406). Body uses the checked Forward rotation replacement and origin yaw, speed min(|delta|/0.4, 0x40A78D36), acceleration 0x436DFFDB, current pan tolerance, zero half-revolutions and absolute mode (0x005655FC–0x005656B4, 0x00517ED0–0x00517F90). Either send failure returns 0x03000016. The runner does not wait for motor acknowledgements.
- Completion variant 3 serializes the current signed face ID as four little-endian bytes (0x00565DA4–0x00565DB4, 0x0075C646–0x0075C672, 0x0075BB9C–0x0075BBC8). Derived teardown clears the tracking field and releases the 0x47 subscription. Shared teardown restores the prior idle parameter if valid, stops body then head in mode 0 or head in mode 1 after start, and calls the driving-animation destruction hook before the generic action tail (0x00565BE4–0x00565C0C, 0x005647B4–0x0056485C). Host callbacks are guarded against stale actions touching the next robot owner.
- The bounded Come Here final stage keeps its behavior's selected face reference and enters tracking before resolving the target. It starts the default action only if the original selected face resolves in the current origin, with no new fallback selection, and stays active until engine time is strictly greater than the deadline (0x005DAB34–0x005DABE8, 0x005DA8FC–0x005DA930). The existing TrackTimeScale caller option can scale the normal 5-second interval. The earlier Come Here selection, turning, verification and drive are outside this slice.
