# AUDIO-PRODUCTION-PATH-GAPS-1

None of the seven listed diagnostic strings appeared in the 40 private hardware-run text logs. The following conclusions also use the actual constructors and shipped library.

* Speech uses SayTextAction and the engine's CannedSpeechOwner. The animation scheduler acquires the same owner's generation through RuntimeAudioSource. OpenSharedAsync makes a NativeWwiseVoiceSession and its owner thread constructs NativeWwiseVoiceHost. The bridge loads the InitScene configuration. WwiseAudioSource.Load is an explicit conformance-tool option (Anim, FreeplayTool and Sing). The WavePortal diagnostic in WwiseAudioSource, step-random selection and sound-library playability belong to that separate C# playback path.
* The shipping AudioAssets.zip contains Init.bnk (3,473 bytes), Music.bnk (1,071,008 bytes) and English(US)/Cozmo.bnk (6,236,403 bytes). InitScene names Music.bnk at 0x0059349C and iterates the load list at 0x008D2F08. CannedSpeechOwner.Open requires it before exposing the shared session. Missing media at startup is a load failure. Optional-bank standalone calls retain an explicit bank-availability error.
* The session closes admission, processes accepted commands and stops game object 7 with native StopAll (0x009A6064). It services actual device completions until pending events have ended and the active effect has terminated (Hijack observation 0x008DBD98/0x008DBDF8), then invokes native sound engine termination (0x0099DCEC). A platform output failure or a completion timeout can instead force release of an active guest. This path reports the original fault, fails waiters and releases the guest without fabricating an EndOfEvent or output-device acknowledgment. The direct-host abrupt-disposal test and the normal completion/StopAll tests exercise the distinction.
* OkaoFaceDetection is constructed on the stock vision path. On setup failure, the eight native branches use specific FaceTrackerImpl.Init keys (delay 0x86B99A, search 0x86BC5A, direction 0x86BD22, pose 0x86BEBA, accuracy 0x86BF82, angle 0x86B798, size 0x86B91A and threshold 0x86BA94). The size-range key contains byte 0x12 in the shipped library. The normal initialization failure state and cleanup remain in place.
* The face tracker appends a default TrackedFace at 0x0086D964 and sets its tracking flag before conversion. The native helper at 0x008FF314 rejects invalid rectangle inputs. At 0x0086D99E a failure bypasses the geometry and timestamp writes, emits the stock warning through sWarningF at 0x0086DE08 and exits the tracker update. VisionSystem consumes the resulting list after the call at 0x006B36DA. The regression test runs both an invalid and a valid size through the real helper, checking the default face, timestamp and warning.
