# ACTIVITY-ID-CONSUMERS-1

ActivityFreeplay starts with a zero child byte and an empty name (0x005AD388–0x005AD39E). On a changed non-null selection it deselects the old child, stores the new pointer, reads the child's IActivity+0x34, sets the parent projection, then invokes the child's OnSelected (0x005ADDFA–0x005ADE1E). The setter reads +0x92 at 0x005AD90E to append the child's enum name to the parent's enum name. Its other string reads replace the old buffer (0x005AD942–0x005AD95E). The destructor reads the old string only for release (0x005AD882–0x005AD896). A null selection retains the last projection.

The Freeplay vtable at 0x010255B8 has 0x005AED3C in slot +0x24. That getter returns the projected +0x94 string. Common lifecycle readers use it as the driving animation key (0x005B3176/0x005B342E), raw idle removal key (0x005B33E8), Activity_ idle key (0x005B32EC/0x005B37D4) and analyzer request key (0x005B31D2/0x005B3474). The stack now owns the projection on the parent and resolves the configured recipients' keys through that same getter. The shipped Freeplay parent in config/engine/behaviorSystem/activities_config.json leaves those parent-level recipient gates off. The interlude Info log at 0x005B3932 and the idle diagnostics at 0x005B32D2/0x005B380C also use the getter. These logging arguments have no consumer effect.

Public state, music and activity DAS remain based on the activity's own IActivity+0x34. OnSelected publishes it at 0x005B314C–0x005B3154 and reports the goal started at 0x005B3210–0x005B3220. OnDeselected uses it in the pending-needs diagnostic and goal-ended report at 0x005B350C and 0x005B360E. BehaviorAudioClient reads the separate public state at 0x00592248–0x00592258. Needs reward cancellation uses the needs flag at 0x005B34FE and calls 0x005B3548. These paths never consume the parent projection.

The real Freeplay test observes Freeplay_Hiking and child ID 5 by the time the Hiking public state is emitted. A configured parent fixture verifies the projected keys in the existing driving, idle and analyzer owners. The reentrant replacement fixture now uses the real child publication at 0x005B3154.
