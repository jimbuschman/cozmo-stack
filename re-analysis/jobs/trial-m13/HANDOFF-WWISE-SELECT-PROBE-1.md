# WWISE-SELECT-PROBE-1

## Source and changes

- SelectPlayable returns no node for an empty playlist. A singleton is resolved directly without allocating selection state, drawing, or checking the node's playability virtual (0xA0A3B4–0xA0A400, 0xA0A654–0xA0A684). Multi-item candidates are looked up in the node registry at 0x9A7EB0 and tested through slot +0x48. A rejected retained node is released through slot +0x0C. Only a successful candidate publishes the selected index (0xA0A55C–0xA0A5C0, 0xA0A6D4–0xA0A6DC).
- Failed sequence candidates advance the same cursor and direction through wrap or ping-pong without drawing (0xA0A524–0xA0A558, 0xA0A614–0xA0A650, 0xA0A6A8–0xA0A6F0). Shuffle mode 1 draws again through SelectRandomly with full bookkeeping for each rejected pick (0xA0A49C–0xA0A4F0, 0xA08A44). A call can repeat an earlier candidate if its shuffle cycle refills during a retry.
- Standard random draws once and scans adjacent indices in wrapped order after rejection. With an avoid window it skips blocked indices. Raw modes 2 and 3 use the played and blocked maps for their forward scan. The first pick and skipped indices count toward the same playlist-length attempt limit (0xA0A448–0xA0A520, 0xA0A5C4–0xA0A610). Each eligible scan candidate updates only the avoid list, blocked bits and remaining count and weight before lookup, even if lookup or playability later fails (0xA08694–0xA087DC). It leaves the played bit and cycle counter alone. The raw mode field survives the two-bit bank load at 0xA08394–0xA083A8. The initial pick uses nonzero-mode eligibility, and only mode 1 recomputes available weight on cycle refill (0xA08ACC–0xA08B3C, 0xA09064–0xA09094).
- For Sound, table 0x103BAD0 + 0x48 dispatches to 0xA1DB58–0xA1DB64 and tests the source ID word at +0x5C. The bank producer reads the MediaId at 0x9B9CC4–0x9B9CE8 and stores it through 0xA1DA8C–0xA1DAA0 and 0xA1EAA0, or 0xA1DA5C and 0xA1EB88. The gate precedes media lookup and decode. For RanSeq, table 0x103B860 + 0x48 dispatches to the constant-true 0x980EE0–0x980EE4, including a nested container whose later selection fails. The same constant applies to Switch, Layer and ActorMixer's checked tables. Across the six local shipped banks, all 468 RanSeq rows are in English Cozmo.bnk. Its 2,190 playlist references resolve to Sound (2,151) or RanSeq (39), with no zero-ID Sound source. Only raw modes 0 and 1 occur, and every container sets the shared-state bit.
- WwiseSelection.cs implements the retry cadence and state transitions. WwiseSoundLibrary.cs supplies the common checked node predicate. WwisePlayback.cs and WwiseSongRenderer.cs already used the same step-selection algorithm. Both now supply that predicate. The managed song path no longer substitutes the first child when selection exhausts (the native failure reaches 0xA0A814–0xA0A82C). WwiseAudioSource.cs shares the container selection owner between ordinary and singing dispatch. Native authored robot audio already executes the original runtime. The separate continuous M6-008 paths do not gain the step predicate.
