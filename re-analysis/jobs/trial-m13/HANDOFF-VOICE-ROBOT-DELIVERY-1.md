# VOICE-ROBOT-DELIVERY-1

## Direct action and recipient

- The bounded entry takes direct English Sentence text with neutral pitch and duration scalar 1. It uses the existing validated, original robot owner and AtEnd external-action admission. It requires mode 2 robot audio, the shipped libraries and resources, the local English banks and a Windows playback device. It returns the admitted runner's native terminal result. Cancellation targets that runner only and cannot cancel another owner or a reused tag (0x00527A74–0x00527A8C, 0x0053D94C–0x0053D970, 0x0053FA4C–0x0053FAB2).
- SayText polls its operation at 0x00561488–0x00561630. The checked path transfers the ready 22,050 Hz mono samples to the session-owned native WavePortal slot (0x0069E9A8, 0x008DC1B8), then creates one live audio keyframe at time zero, volume and probability 1, and the one-loop animation child (0x0056153C–0x005615DC). Style 3 selects Sentence and the Processing event (0x00C573B0, 0x0069EE20). The native switch and pitch are in place before the child posts the event (0x00561728–0x00561754). The child uses the existing matching firmware CA then CB and cancellation delivery. The parent delegates Update (0x00561D4C) and tears down its own operation and child (0x005613D8–0x00561436).
- Speech selects the robot audio recipient only for that exact live clip and original owner in the existing streamer transaction. Game object 7 routes to plug-in 1 and Robot_Bus_1 with aux 1 and dry 0 (0x0059962A, 0x00599952–0x005999A4). Init consumes its AudioKeyframe iterator (0x0059687E–0x00596914). The event posts from the independent dispatch path, applies event_volume, then requests render (0x00597F00, 0x0059826C–0x0059829E).
- Native Hijack opens the back stream, copies each frame before guest reuse, and closes that stream (0x008DBD98, 0x008DC040, 0x008DBDF8, recipients 0x005984E8, 0x005985FC, 0x0059878C). Robot audio consumes the front stream. State 1 can send silence, state 2 waits for the next frame, and state 3 encodes float samples or distinguishes an absent frame from a present empty frame (0x00597C6C–0x00597D82, 0x00597DB4–0x00597E90). EndOfEvent and Hijack close remain independent.
- The existing streamer owns wire transmission, never the native worker. It uses the robot AnimationState counters and 14-audio/8192-byte limits (0x0057C6F6–0x0057C7AC), emits 744-byte 0x8E or 0x8F before the first 0x9B (0x0057C016–0x0057C056, 0x0057C8E4–0x0057CABE), and advances its 33 ms frame clock according to the same drain path. End is reliable, direct and after the clip, recipient and FIFO complete (0x0057C448–0x0057C496, 0x0057CB44–0x0057CBB0). Abort uses 0x8D and the reset/StopAll path (0x0059678E–0x005967B8). A stopped session refuses delayed event posts and discards retired frames.

## Platform input

- The Windows device receives the actual 4096-byte dry PCM blocks through WinMM at the checked 48 kHz stereo geometry. Each block stays tied to its guest FIFO token until a real device completion. The single ARM owner acknowledges the oldest returned token, runs the native OpenSL queue callback 0x00A582F8 and renders on its own clock. Reset-returned buffers never count as consumption. Watchdogs fail without supplying completions. This host platform input is separate from the robot's animation counters. Android absolute callback cadence remains hardware-only. [WinMM open](https://learn.microsoft.com/en-us/windows/win32/api/mmeapi/nf-mmeapi-waveoutopen), [completion](https://learn.microsoft.com/en-us/windows/win32/multimedia/wom-done), [reset](https://learn.microsoft.com/en-us/windows/win32/api/mmeapi/nf-mmeapi-waveoutreset)
