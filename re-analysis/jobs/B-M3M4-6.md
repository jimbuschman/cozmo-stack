## 1. Blocking

1. **Deadlock in `BlockWorld.ApplyMovedOrStopped`** (`Vision/BlockWorld.cs:2481-2489`).
   - The function now holds the world `_gate` across `MarkObjectDirty`, which raises `PoseStateChanged`
     (`SetPoseStateHelper`, :1781) under that lock.
   - The subscriber `ManipulationSystem.cs:37`, through `Configurations.Update()`, takes `_updateGate`
     (`BlockConfigurations.cs:129`).
   - `BuildLocked` takes `_updateGate` and then the world `_gate` (:1034), from the vision worker and from behaviours.
     That is ABBA.
   - **Fix:** do the state changes under the lock, and raise `PoseStateChanged` after it is released, in the same order.
   - **Test** the cross-thread order: a subscriber that takes `_updateGate` while another thread runs `BuildLocked`.
2. **Cube connection: the world registration must come before the light play.**
   - In the engine, `BlockWorld::AddConnectedActiveObject` (0x00533BD6) runs before
     `Robot::Broadcast(ObjectConnectionState)` (0x00533D2C), and the broadcast is what reaches CubeLightComponent.
   - In the stack, `Broadcast` runs `DeviceRoute` (Cubes, then `Lights.PlayLightAnim("WakeUp")`) before `PublicRoute`
     (`VisionSystem.cs:670/696`, the only `AddConnectedActiveObject` caller). So the world lookup is empty, the play
     logs MISSING, and the cube never lights.
   - **Fix:** make `AddConnectedActiveObject` run before the light component sees the connection state.
   - **Test** through the entry, a raw ObjectConnectionState message, **without** pre-registering the world object.
     `M4ControlTests.cs:180` (`Rig.Data`) pre-registers it; change that fixture so it doesn't (CHECKLIST §1).
3. **NV timeout order** (`NvStorage.cs:984-985`).
   - The binary's order is `sWarningF` `Update.ReadTimeout`/`WriteTimeout` (0x00645782), then the callback (0x006457BC).
   - Deliver the warning to log subscribers before the callback runs. Test the order.
4. **NV write-result order** (`NvStorage.cs:1275-1280`).
   - The binary's order is:
     1. the `HandleNVOpResult.Recvd` debug (0x00642FFE);
     2. `BroadcastNVStorageOpResult` (0x0064339E);
     3. `ExecutingWriteCallback`;
