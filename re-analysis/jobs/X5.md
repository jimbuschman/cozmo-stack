# Job X5: extraction of M6 exact IMDCT and M6-020

**Agent:** opencode (DeepSeek), window 2. **Type:** extraction (read-only).

## Scope

1. **The Vorbis IMDCT, exact (M6 correction C8, M6-002).**
   - Operator decision: exact, always.
   - Recover the per-lane arithmetic and table indexing of the NEON inverse MDCT, instruction by instruction, and the 615-float master table with its 13 views, byte for byte.
   - Start from `re-analysis/evidence/m6-vorbis/vorbis-imdct.md`, then the inventory `re-analysis/inventory/M6-wwise-bank.md` (C5..C8).
   - Ghidra decompiles NEON poorly: read the instructions.
   - The report must be complete enough to transliterate the kernel with no guesses. It lists every instruction range and every table offset.
2. **M6-020:** the STMG group-item field meanings and the two trailing bodies.

## How to do it

1. Read `re-analysis/jobs/README.md`, then `AGENTS.md`, then `.opencode/agent/cozmo-extractor.md`. Follow the extractor role exactly, whichever agent you are.
2. Claim the job: write `re-analysis/jobs/status/X5.md` with `CLAIMED <agent> <date time>`, then commit and push that file alone.
3. Work through the subsystems below in order. Write one report per subsystem to `re-analysis/research/<yyyymmdd>-X5-<subsystem>-extraction.md`, with:
   - the row table `step | what the original does | citation | record id or NEW | classification`;
   - every existing record of that subsystem in `re-analysis/fidelity_manifest.json`, judged confirmed, too weak or contradicted, with the citation;
   - NEW steps that no record covers;
   - open questions.
4. Use the Ghidra decompilation (`re-analysis/decomp/libcozmoEngine/`, `index.tsv`) to find and read functions. Cite and check the instructions in the `.so`, never the pseudo-C.
5. After each report: add it and your status file, commit, `git pull --rebase`, push. Push reports as they finish; don't hold them until the end.
6. When all are done, set the status to `DONE <date time> <one-line summary>`. If you can't go on, set it to `BLOCKED <reason>`. Push.

**Write scope:** `re-analysis/research/<yyyymmdd>-X5-*` and `re-analysis/jobs/status/X5.md`. Nothing else: no code, no manifest, no inventories, no PROJECT_STATE. Scratch files go in `.scratch/X5/`.
