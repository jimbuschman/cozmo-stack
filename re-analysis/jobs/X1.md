# Job X1: extraction of M11-vision, then M12-manipulation

**Agent:** opencode (DeepSeek), window 3. Codex may take it instead. **Type:** extraction (read-only).

## Scope

1. **M11-vision:** the whole production vision path.
   - It covers image hand-off from M3, the VisionComponent gates and mailbox, the marker front end (the live extractor is the ecvcs integral-image variant, M11-032), quads, corner refinement, decode, pose, BlockWorld, and the game broadcasts.
   - Earlier work to build on, never to copy: records M11-001..M11-034; `re-analysis/evidence/m11/`; branch `m11-wip` (an unverified partial rework, leads only); tag `archive/m11-research-package` (leads only).
   - Settle the RECOVERABLE_GAP records M11-021, M11-023, M11-027 and M11-029 exactly.
2. **M12-manipulation:** pre-action poses, path packing, docking (DockWithObject, DockingErrorSignal, PickAndPlaceResult), pick-up and place verification, roll and mount, and the carried-object pose chain. Existing records: M12-001..M12-016.

## How to do it

1. Read `re-analysis/jobs/README.md`, then `AGENTS.md`, then `.opencode/agent/cozmo-extractor.md`. Follow the extractor role exactly, whichever agent you are.
2. Claim the job: write `re-analysis/jobs/status/X1.md` with `CLAIMED <agent> <date time>`, then commit and push that file alone.
3. Work through the subsystems below in order. Write one report per subsystem to `re-analysis/research/<yyyymmdd>-X1-<subsystem>-extraction.md`, with:
   - the row table `step | what the original does | citation | record id or NEW | classification`;
   - every existing record of that subsystem in `re-analysis/fidelity_manifest.json`, judged confirmed, too weak or contradicted, with the citation;
   - NEW steps that no record covers;
   - open questions.
4. Use the Ghidra decompilation (`re-analysis/decomp/libcozmoEngine/`, `index.tsv`) to find and read functions. Cite and check the instructions in the `.so`, never the pseudo-C.
5. After each report: add it and your status file, commit, `git pull --rebase`, push. Push reports as they finish; don't hold them until the end.
6. When all are done, set the status to `DONE <date time> <one-line summary>`. If you can't go on, set it to `BLOCKED <reason>`. Push.

**Write scope:** `re-analysis/research/<yyyymmdd>-X1-*` and `re-analysis/jobs/status/X1.md`. Nothing else: no code, no manifest, no inventories, no PROJECT_STATE. Scratch files go in `.scratch/X1/`.
