## Item 4: why no interleaving remains

- **The three writers share one gate.** Every writer of MainPose, the lift node, the carried object's node, and the origin
  map (`_nativeOrigins`/CurrentOriginId) takes `EngineRobot.PoseTreeGate`:
  - Delocalize, from AddNewOrigin through the carried UpdateObjectOrigin loop;
  - ComputeLiftPose;
  - UpdateCarriedObjectPose's tree branch, including its origin check;
  - SetObjectAsAttachedToLift's re-parenting.
- **So the race is gone.** The worker's "origin unchanged → write MainPose" can no longer straddle a Delocalize's reset
  and re-parent.
- **Lock order:**
  - The vision worker holds VisionSystem `_busy` (FrameProcessed), then takes PoseTreeGate, then the history lock.
  - The message thread takes PoseTreeGate, then BlockWorld `_gate`, the history lock, and the Motion `_gate` (for
    PublicationHeadAngle).
  - No path takes PoseTreeGate while holding any of those, so there is no cycle.
- **What the gate does not cover:**
  - Readers that flatten the tree without the gate (`ObservableObject.Pose` getter) can still read a node mid-write. The
    check didn't raise this.
  - Engine log fan-out (LogEntry subscribers) runs inside the gated region.

the gate, ComputeLiftPose, Delocalize and (with the marker library) UpdateCarriedObjectPose don't complete. They complete

### 1. The reader-side race

**What changed.** `PoseTreeNode.Transform` (`Vision/Geometry.cs:153-159`) is now a property over an immutable
`TransformBox`:
- it is published with `Volatile.Write`;
- it is read once per access with `Volatile.Read`;
- the `Transform3d` value is copied unchanged, so results stay bit-identical.

The vision worker's flatten (`ObservableObject.Pose` → `GetWithRespectToRoot`) therefore sees each node's old or new
transform whole, never a torn mix. No lock is taken on the reader side, so the lock order is unchanged and there is no
cycle.

**In-place mutators** now read once, compute on a local, and publish once:
- `Pose3d.MultiplyBy` reads b before writing this, so the copy matches an aliased call;
- `Pose3d.PreComposeWith` keeps R26's aliasing: the same node calls `t.PreComposeWith(ref t)`;
- the `Pose3d(Pose2d)` constructor's plane step, `PreComposeWith(ref plane)` (`Vision/Geometry.cs:232`);
- the three walk steps of `GetWithRespectTo`, and its final inverse/multiply.

- **Staleness across threads.** A reader can see the previous lift angle.
- **A rule 12 placement to review, not moved in this job.** Natively one thread reads and writes these. In the stack the

### Round 3, q1: the stress test's angles

Using the stack's lift-pose code, ComputeLiftPose rotates by +angle and back by −angle (OV01 L5–L8). The published lift
rotation is therefore the identity up to rounding.

**Angles tried:** 0.1 against each of 0.6, 1.2, 0.3, 0.45, 0.7, 0.85, 1.0, −0.2, 0.25, 0.55, 0.9 and 1.1. Every
rotation came out bit-equal. So no angle pair can make a rotation-field tear visible, and such a tear would be harmless.

**What the test now asserts** (angles 0.1 and 1.2):
- the two lift rotations are equal, kept so that a change gets noticed;
- the lift translations differ in X and in Z;
- the flattened cube translations differ in X and in Z.

A torn mix of the translation's float fields, or of one transform's rotation with the other's translation, therefore
yields a third value, which the assertion rejects. Detection stays probabilistic: a tear has to happen during the run.

### Round 3, q3: correction to the round-2 note on rethrow timing

The round-2 text says an unowned exception is rethrown "as an undeferred call would have thrown it to its caller". That
is not the same timing:
- **Undeferred:** the exception would be thrown at the emission point, inside the gated body, and would abort the
  body's remaining steps.
- **Deferred:** the body runs to completion, the gate is released and the whole queue drains. Only then is the first
  unowned exception rethrown, and only if the body completed normally.

So a throwing unowned subscriber (the static MISSING channel or the DAS observer) no longer cuts the gated body short.
