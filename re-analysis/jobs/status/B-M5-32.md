## Joins

- Send join (`M5HwAnalysis.JoinSends`): successful gate sends and the direct End from one second before the window to
  its end, in send order, must equal exactly one contiguous run of the deduplicated outbound stream-tag messages
  (0x8E, 0x8F, 0x91..0x95, 0x97..0x9B) by tag and EngineToRobot size, each captured at or after its gate stamp and
  within one second. Zero or several runs: unjoined, with the reason. Time bounds candidates; order and content decide.
- LAYERS: each frame's audio/face buffer sequence -> its joined wire message -> FaceActivity keyed by the audio's frame
  line and ordinal. Unjoined frames, or a set flag with no buffered face, stay unjoined; FiniteLayers then INCONCLUSIVE.
- PARAMETERS: KeepFaceAlive calls stamped after the 44000/45000 readback (the B4 write and KeepFaceAlive share the
  scheduler lock). The verdict is now the Blinks verdict; the physical answer stays a separate observation.
- AUDIO: gate rows in the window as coherent BudgetAdmission, all refreshes. Positive
  (OBSERVED_AUDIO_FRAMING_AND_ADMISSION, budgetCompliance OBSERVED_FOR_JOINED_WINDOW) only when framing is observed,
  every outbound audio message in the window is joined, every refresh matches C9 and every gate remainder matches C14's
  successful-send accounting. Mismatch: OBSERVED_ADMISSION_ACCOUNTING_MISMATCH.
- DRIVING: verdict = phase verdict when OBSERVED_SUCCESSFUL_START_LOOP_END_REQUESTS or OBSERVED_FAILED_START_END_CLEANUP,
  whatever the drive result (the M5Hw drive-result override removed); loopRequestCovered/loopCoverageOpen added;
  successfulTraversalCoverage false, traversal NOT_JUDGED and assigned to M12/M13. Contradictions stay non-OBSERVED.

## Choices for the manager

- Join margin 1000 ms (harness choice) for both the pre-window inclusion and the capture-after-gate bound.
- Zero-size buffer entries (stack bookkeeping) are not reported; a direct End reports Admitted=false, DirectBypass=true.
- Observation records are allocated only while subscribed; the direct-End snapshot then takes the buffer's own leaf lock.
- `_budgetEpoch` is cleared when unobserved, on Unlimited (test seam) and on ResetToConstructed, so no gate row is
  attributed to a stale refresh.
- AUDIO's positive budgetCompliance label covers the joined window only, not every send of the run.
- Blinks receives calls only; generated blinks are not additionally joined to face wire messages.
