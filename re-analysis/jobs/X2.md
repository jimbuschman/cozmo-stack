# Job X2: extraction of M13-navigation, then M14-faces

**Agent:** opencode (DeepSeek), window 3, after X1. Codex may take it instead. **Type:** extraction (read-only).

## Scope

1. **M13-navigation:** the lattice planner and its motion primitives (cozmo_mprim.json), obstacle expansion, path following, the charger (geometry, the mount, driving off the contacts), FlipBlock, AlignWithObject, and pop-a-wheelie. Existing records: M13-001..M13-015.
2. **M14-faces:** the face pipeline up to and around the OKAO boundary.
   - OKAO itself is BLOCKED_EXTERNAL; say exactly where the boundary is.
   - Also cover TrackedFace geometry, FaceWorld matching and forgetting, face enrolment and the album (the NV reads 0x184000/0x183000 are M3-033's), and the game broadcasts.
   - Existing records: M14-001.., plus M11-016 (face, pet, motion).

## How to do it

1. Read `re-analysis/jobs/README.md`, then `AGENTS.md`, then `.opencode/agent/cozmo-extractor.md`. Follow the extractor role exactly, whichever agent you are.
2. Claim the job: write `re-analysis/jobs/status/X2.md` with `CLAIMED <agent> <date time>`, then commit and push that file alone.
3. Work through the subsystems below in order. Write one report per subsystem to `re-analysis/research/<yyyymmdd>-X2-<subsystem>-extraction.md`, with:
   - the row table `step | what the original does | citation | record id or NEW | classification`;
   - every existing record of that subsystem in `re-analysis/fidelity_manifest.json`, judged confirmed, too weak or contradicted, with the citation;
   - NEW steps that no record covers;
   - open questions.
4. Use the Ghidra decompilation (`re-analysis/decomp/libcozmoEngine/`, `index.tsv`) to find and read functions. Cite and check the instructions in the `.so`, never the pseudo-C.
5. After each report: add it and your status file, commit, `git pull --rebase`, push. Push reports as they finish; don't hold them until the end.
6. When all are done, set the status to `DONE <date time> <one-line summary>`. If you can't go on, set it to `BLOCKED <reason>`. Push.

**Write scope:** `re-analysis/research/<yyyymmdd>-X2-*` and `re-analysis/jobs/status/X2.md`. Nothing else: no code, no manifest, no inventories, no PROJECT_STATE. Scratch files go in `.scratch/X2/`.
