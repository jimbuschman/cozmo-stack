## Items

1. **Re-read the current layer after each pop and callback (objection 1).** In CubeLightComponent.Update, after every pop and
   callback re-read `CurrentLayer` and its list before the size and back-node reads, as native 0x00637A0A..0x00637A18 and
   0x00637A4A..0x00637A62; then PlayingPrevious / SetObjectLights on the re-read layer (0x00637A6C..0x00637AE4). Production
   regression: A on layer 2 with a callback that plays B on layer 1; at A's end the wire carries B's resend and the
   component stays on layer 1.
2. **No interleaved Updates (objection 2).** A callback must not open a window in which a host-thread entry runs its own
   Update on the same stacks. Native runs the game messages (EnableCubeSleep, EnableGameLayerOnly and the other public
   light entries) one at a time on the engine thread, never inside an Update. Post those public entries to the engine thread
   (as B-M3M4-30 did for the camera calls, `InvokeCameraRequest`) so Update can keep the component lock for its whole body
   while the callback runs reentrantly on the engine thread. Regression: a callback running while a host
   EnableCubeSleep(false) / EnableGameLayerOnly arrives sends no duplicate OffLights or default.
3. **Pose-state callback from SetPoseStateHelper (objection 3).** Wire OnActiveObjectPoseStateChanged (same IsActive gate,
   same arguments) from SetPoseStateHelper (`BlockWorld.cs`:2069-2080; native `b.w` 0x00506176), so MarkObjectDirty
   (0x005075AC/0x005075B2, reached from HandleActiveObjectMoved at 0x0053413C; `BlockWorld.cs`:2951-2965 and :2722) reaches the
   cube lights, as BroadcastObjectPoseChanged's caller already does. Production regression: a Known cube receives an
   ObjectMoved robot message through the dispatch and the wire carries Connected on layer 2. Correct the status file's
   "other host pose-state notifications are not widened".
4. **Labels (objection 4 and queued).** Relabel `ActivePoseChangeReachesCubeLightsBeforeTheHostPoseNotification` as unit (it
   substitutes the internal ApplyRelativeObservation) and in M4-049's `test`; the item-3 test is the production one.
   Relabel `RealDelocalizePlaysConnectedOnNonCarriedCubesInSignedIdOrder` as unit, and add negative ObjectIDs (or IDs that
   order differently signed and unsigned) so it tests signed order.
