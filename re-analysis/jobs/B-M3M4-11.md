## 1. Blocking

1. **Convert at the native call points, in native order** (Lights.cs:228-235, AddStateValues).
   - AddBackpackLightStateValues reads seven fields in order. Each helper converts all 5 elements inside its own loop:
     - onColors: GetColorValuesToArrayOptional, 0x586D4E (asFloat 0x5871F8..0x587234);
     - offColors: the same helper, 0x586D82;
     - the four periods: GetArrayOptional<unsigned,5> at 0x586DB4, 0x586DE6, 0x586E16, 0x586E4C (GetValue<unsigned>
       0x5873DA);
     - offset: GetArrayOptional<int,5>, 0x586E7E (GetValue<int> 0x58741E).
   - Only then are the seven results ANDed (0x586E82..0x586E96), followed by the validity branch (0x586EA8) and the
     insert/existing-key path (0x586EB2).
   - So a JsonCpp throw in any field comes **before** the InvalidJson check and the existing-name check. Under
     M1-034, that skips the whole file: no InvalidJson, no error flag, and no later state from that file.
   - Restructure to match: field by field, converting as read, then decide.
   - Tests:
     - a bad colour component plus a missing `offset`: file skipped, no InvalidJson, no error flag;
     - a second file redefining "charging" with onPeriod -1: whole file skipped, including its other states;
     - several bad values: the skip log names the first native throw.
2. **Index with JsonCpp's `operator[](unsigned) const`** (Lights.cs:241 `c.Elements[i]`, :231-235).
   - 0x5871EE/0x5871F4 → 0x8EA6DC:
     - a null value returns nullSingleton (0x8EA6EC → 0x8EA70A);
     - an array index that isn't present returns nullSingleton (0x8EA702 → 0x8EA714), which asFloat turns into 0;
     - any other type throws LogicError (0x8EA6EA → 0x8EA736).
   - Use or add that accessor in the stack's JsonCpp port (FirmwareJson.cs) for every indexed read here. A short colour
     array then reads 0 for the missing elements, and a non-array colour entry is a JsonCpp throw (M1-034 skip), never
     an ArgumentOutOfRangeException.
   - Tests: `[1,0,0]` gives the missing elements as 0; a colour entry that is a number gives an M1-034 file skip.
