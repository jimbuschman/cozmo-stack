# Job B-M12: build M12-manipulation from its approved inventory

**Agent:** opencode, as cozmo-manager, in this window's own clone. **Type:** build. **Needs:** job I-M12 DONE. If it isn't, set this job's status to `WAITING I-M12` and end.

## How to do it

0. Read `re-analysis/jobs/README.md`, `AGENTS.md` and `.opencode/agent/cozmo-manager.md`. Exact, always; no guesses.
1. **Claim the job:** write `re-analysis/jobs/status/B-M12.md` with `CLAIMED <date time>`, then commit and push that file alone.
2. **Compare the code with every row** of `re-analysis/inventory/M12-manipulation.md`. Existing code is a candidate: what the rows support stays, and what they don't is repaired or rebuilt.
3. **Build it in one batch.**
   - `@cozmo-implementer` implements every discrepancy and **wires the layer into the live production path**. Code nothing calls has changed nothing the robot does.
   - A `MISSING:` goes to `@cozmo-extractor`. If the answer changes a row, add it as an inventory correction and run `--approve` again.
4. **Verify it:** `@cozmo-verifier` checks the whole diff. Fix every blocking finding, then re-verify the fixed hunks.
5. **The records:**
   - settle each record whose whole path is now built and verified: EXACT_SOURCE, or EQUIVALENT_IMPLEMENTATION only under SD1's rule;
   - a record whose path depends on a layer not built yet stays IMPLEMENTATION_GAP, with `unresolved` naming that layer (SD3).
6. **The gates:**
   - `fidelity.py --check` passes;
   - the verifier gives PASS;
   - the full suite passes, with `AssetPresenceTests` green.
7. **Commit and push:** commit only this job's files, then `git pull --rebase`.
   - If the rebase conflicts in code shared with another window (for example `CozmoEngine.cs` or `CozmoRobot.cs`), keep both sides' intent, rebuild, and run the full suite again.
   - If you can't resolve a conflict, set `BLOCKED <the conflict>`.
   - Then push. The push gate runs the suite again.
8. **Finish:** set the status to `DONE <date time>`, with:
   - the commit hashes;
   - the records settled;
   - the gaps left, with their layers;
   - any robot check the operator should run. Write the steps; don't wait for the run.

**Write scope:**
- the code and tests for this layer under `cozmo-stack/` (list anything outside the layer's usual folders in the status file);
- this subsystem's records in the manifest, plus `re-analysis/FIDELITY_GAPS.md`;
- a correction section in `re-analysis/inventory/M12-manipulation.md`, with its re-approval, if a MISSING changes a row;
- `re-analysis/jobs/status/B-M12.md`.

No other subsystem's records or inventories.
